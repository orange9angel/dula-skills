# 行走循环（walk cycles）：cel 数量、生成顺序与验收

2026-07 rainy_rooftop_cat 三轮翻车后定型。教训按时间顺序：

1. **同一相位**：alt 帧照抄参考图的腿部相位，交替时腿不动。
2. **脚向拧反**：强制模型画「相反触地相」，腿换过来了但鞋尖不朝行走方向（脚像反装）。
3. **2-cel 不自然**：触地↔过渡两帧交替没有错误，但观感是原地踏步/生硬。

## cel 数量分级

| 方案 | cels | 观感 | 用法 |
|------|------|------|------|
| 最低可用 | 2（触地A ↔ 过渡A） | 像踏步，低频切换时生硬 | 只用于 ≤1s 的短经过镜头 |
| 可接受 | 3（触地A → 过渡A → 触地B） | 基本自然 | 1–2s 行走段 |
| 推荐 | 4（触地A → 过渡A → 触地B → 过渡B） | 自然的完整一步 | 默认目标 |

播放速率：4–6 cel/秒（约每秒 1–1.5 步）。每张 cel 在时间线上的驻留 ≥0.15s，
低于 0.1s 会闪成噪点而不是运动。

> 不全来自 cel 数量；背影镜头的 A/B 相位差要做得比侧景更夸张才可读。

## 生成顺序（按模型可靠性排序）

1. **触地A**：通常就是已有基帧，无需生成。
2. **过渡A（passing）**：以触地A为参考做局部编辑——支撑腿直立全脚掌落地、
   摆动腿屈膝抬起经过、抬脚离地鞋尖朝下。模型最可靠的姿态，优先生成。
3. **触地B（相反触地）**：最难。不要以触地A为参考硬换（会被锚定/拧脚向）。
   以**过渡A为参考**继续走半步（摆动腿向前落地成前支撑、原支撑腿后蹬），
   并在 prompt 里逐字写清每条腿的位置和鞋尖朝向；或做腿部区域单独编辑再回填。
4. **过渡B**：以触地B为参考，同第 2 步。

每一张入库前必须通过验收，再作为下一张的参考（approve before inheriting）。

## 验收清单（逐张核对，缺一不可）

- 哪条腿在前/承重（指名核对，不接受「图出现了」）；
- 鞋尖朝向 = 行走方向（侧景）或鞋底自然可见（背影抬脚）；
- 摆动脚明确离地，支撑脚全脚掌落地；
- 脚踝/膝盖弯曲方向符合人体结构，无多余肢体；
- 尺寸与基帧一致（不同尺寸会造成交替时取景跳动）；
- 串成循环后抽帧对比相邻 cel：腿的位置必须逐级推进，不能有两张相同相位。

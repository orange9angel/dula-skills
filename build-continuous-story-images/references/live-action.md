## Moderation Map（审核地图）

- 上传拟真人脸**图片** → 拦（I2V 首帧 + 2.5 多模态图片参考，AI 生成的脸也算）
- 含人脸的**生成视频**作 `reference_video` → 放行（身份在模型内闭环）
- 输出端也有审核，会对措辞误杀（具体年龄、风格名）——改写 prompt 重试
- 猫/动物不受人脸墙限制
- 绕审核的正解是让输入不含可疑对象，不是把脸藏到视频后段

## World Anchor Workflow（世界锚点工作流）

1. **先建锚点再开拍**：一条主场景视频（或插画管线的场景母版图）。
2. 环境/非说话镜：锚点帧 → I2V（2.0 便宜通道）。
3. 角色建立镜：在锚点世界里 T2V（人或猫）。
4. 说话镜：建立镜作 `reference_video` + TTS 作 `reference_audio`（≥1.8s）。
5. 音频：模型输出是音色克隆而非 TTS 波形拷贝——要系列声线一致就后期换回原 TTS
   轨并验证对齐（偏差 >0.15s 保留模型轨并记录）。
6. 环境音：三底床（水/鸟/叶）全片连续铺满，语音槽压 0.6–0.7 不消失；
   omni/DA 段自带人声叠在底床上，不得替换底床。
7. 批次生成前，先用一镜验证与**本集既有素材**的脸/景一致，再放全量
   （链内一致 ≠ 与本集一致）。

## Cost Data Points（成本基线）

- I2V 实时扣费，余额差可精确核对；OmniHuman/TTS/DreamActor 延迟结算，
  大额制作前后各查一次余额（volc-balance skill）。
- 参考类任务 token ≈ 纯 T2V 的 2 倍。
- E06-live 全片参考：V1（三通道混合）≈¥64–72；V2 视频链 9 镜 ≈¥132
  （含重试废案）；失败任务按惯例不计费但未逐笔核账。
- Seedance 2.5 开通门槛：余额 >¥200。

## Character Identity Management（角色身份管理）

真人管线的角色锚点**必须是视频**（脸要生在模型内部），与动画/猫管线
（图片锚点 + I2V）根本不同。审核按"脸的来源"执法：模型内部生成的 →
放行；用户上传的图片 → Seedance 拦、即梦 avatar 家族放（产品定位不同）；
本地工具 → 无审核。一句话：**图片是"证"，视频是"人"**。

三条身份路径（按优先级）：

| 路径 | 做法 | 脸的保真 | 成本 | 状态 |
|---|---|---|---|---|
| **平台主体库** | 文生图定稿 → 主体识别 API 登记（`jimeng_realman_avatar_picture_create_role_omni_v15`）→ 生成时引用 role_id | 像素级（静帧定稿） | 登记一次 ~¥1 | **待验证**（avatar 家族吃人脸图片，AI 脸大概率放行；未知：可引用于哪些生成接口） |
| **内部定稿 + 视频参考链** | 文生图海选方向（¥0–2）→ T2V 决赛（¥5–10）→ 监制挑脸 → 建立视频作 `reference_video` 锁全片 | 模型给什么挑什么（方向可控、单脸随机） | ~¥7–12/角色，一次性 | **已验证**（锁脸/锁景 5/5） |
| **DA 特种通道** | 指定静帧 → DreamActor 驱动成建立视频 → 进参考链 | 精确（指定那张脸） | ~¥5–7/镜 | 已验证（DA 视频作 reference_video 待验证） |

决策树：图片阶段"方向不错"→ 内部定稿；"非这张脸不可"→ DA；
角色要长期持有 → 优先验主体库。定稿成本是一次性户口费，摊到连载
每集 ≈¥1.5，远低于身份失败的批次返工（E06-live V2 教训 ¥110）。
本地换脸（facefusion）仅兜底：与云 API 管线不同构、只换面部区域。

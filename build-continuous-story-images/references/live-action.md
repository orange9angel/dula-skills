## Moderation Map（审核地图）

- 上传拟真人脸**图片** → 拦（I2V 首帧 + 2.5 多模态图片参考，AI 生成的脸也算）
- 含人脸的**生成视频**作 `reference_video` → 放行（身份在模型内闭环）
- 输出端也有审核，会对措辞误杀（具体年龄、风格名）——改写 prompt 重试
- 猫/动物不受人脸墙限制
- 绕审核的正解是让输入不含可疑对象，不是把脸藏到视频后段

## World Anchor Workflow（世界锚点工作流）

1. **先建锚点再开拍**：一条主场景视频（或插画管线的场景母版图）。
2. 环境/非说话镜：锚点帧 → I2V（2.0 便宜通道）。
3. 角色建立镜：在锚点世界里 T2V（人或猫）。
4. 说话镜：建立镜作 `reference_video` + TTS 作 `reference_audio`（≥1.8s）。
5. 音频：模型输出是音色克隆而非 TTS 波形拷贝——要系列声线一致就后期换回原 TTS
   轨并验证对齐（偏差 >0.15s 保留模型轨并记录）。
6. 环境音：三底床（水/鸟/叶）全片连续铺满，语音槽压 0.6–0.7 不消失；
   omni/DA 段自带人声叠在底床上，不得替换底床。
7. 批次生成前，先用一镜验证与**本集既有素材**的脸/景一致，再放全量
   （链内一致 ≠ 与本集一致）。

## Cost Data Points（成本基线）

- I2V 实时扣费，余额差可精确核对；OmniHuman/TTS/DreamActor 延迟结算，
  大额制作前后各查一次余额（volc-balance skill）。
- 参考类任务 token ≈ 纯 T2V 的 2 倍。
- E06-live 全片参考：V1（三通道混合）≈¥64–72；V2 视频链 9 镜 ≈¥132
  （含重试废案）；失败任务按惯例不计费但未逐笔核账。
- Seedance 2.5 开通门槛：余额 >¥200。

## Relay Discipline（中断接力纪律）

- 长管线会被 5 小时用量窗口打断：所有生成脚本必须幂等（存在即跳过）、
  提交先落盘 taskId、轮询超时只续查不重复付费。
- 交接文档范本：`dula-story/episodes/cat_leads_e06_cat_model_live/V2_HANDOFF.md`
  （零新增花费核对存量、明确标注"未验收项"、成本分项、重建命令）。

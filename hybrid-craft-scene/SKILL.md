# Hybrid Craft Scene（文生图 × 程序化 3D 混合场景）

**场景烟火必须使用粒子。** 火把、炉火、火盆、烛火、烟、余烬与火星沿用
[粒子特效规则](../direct-animation-craft/references/particle-effects.md)。背景绘画保留；
其中烤死的火焰须局部清除后接粒子，禁止几何火舌、菱形光斑或静态火图充当动态火。
发射器跟随场景/背景坐标，实际照明与火势使用同一包络，检查摄影变化下的锚定和遮挡。

用户要求可动画的金属铠甲或用文生图做圣衣纹理时，读
[有动作的金属圣衣](references/animated-metal-armor.md)：保留已有动作与脸，分别处理
生成刻纹、材质反射、甲片曲率和饰件跟随；不要只把高光画死在底色上。

程序化 3D 场景的"片场感"根因通常不是 3D 本身，而是**纯色零纹理 + 几何太规则 + 光太平**。
本工艺只把"皮肤"交给文生图：几何、绑定、动画、光影全部留在程序化侧，相机与交互自由度不变。

**场景轮廓本身太规则时，先分清替换范围。** 加石纹不会改变等宽柱列、重复台阶和
棋盘地砖的形状。有限机位的二维试片可联用 [draw-over-animation](../draw-over-animation/SKILL.md)，
保留动作空间与关键接触关系，重画石块尺度、缺口、边缘节奏和阴影大形；不能只用
颗粒或抖动制造“手绘感”。整幅近景背景板会限制绕拍和地面视差，必须在实际镜头
检查脚地关系与遮挡，不能继续声称保留了原三维的全部摄影自由度。

只换场景、恢复原3D人物的固定机位实验，可复用
[绘画底图与3D人物分离](../draw-over-animation/references/sprite-atlas-trials.md#先换场景保留原人物)
中的共享模块；人物表演、底图绘画、阴影与遮挡分别验收。

**参考实现**：`dula-story/episodes/bio_armor_academy_s1e2/`（`tools/gen_textures.py` +
`scenes/RuinsDuskScene.js` 的 `applyHybrid()`，2026-10-08 R4 验证）。

## 分工原则

| 归文生图 | 归程序化 3D |
|---|---|
| 材质纹理（泥地/混凝土/锈钢/布料） | 几何、UV、遮挡、碰撞 |
| 远景背景板（matte painting：天空/天际线） | 相机运动、角色动画、口型 |
| —— | 光影方向（纹理必须无方向性阴影，光影归灯光） |
| —— | 中近景道具轮廓（AI 纹理只提供表面细节） |

## 纹理 prompt 纪律

- 关键词：`无缝平铺材质贴图` + `正俯视/正视` + `均匀散射光` + `无强烈方向性阴影` +
  `无文字无人物` + `四方连续`。**纹理里烤进方向性阴影是最常见翻车**（和场景灯光打架）。
- 模型出图不是真无缝：Three.js 侧用 `MirroredRepeatWrapping` 镜像平铺，免接缝零后处理。
- 逐文件落 `source.json`（provider/model/prompt/sha256），生成脚本 skip-if-exists。

## 背景板纪律

- 一次生成"天空+天际线+太阳"整幅宽幅（如 2048×768），替换程序化天空渐变和剪影楼群；
  prompt 里钉死太阳位置（"画面左三分之一处"）和地平线高度（"下三分之一"）。
- **单张平面背景板只覆盖主视野方向**：侧向机位（过肩、侧拍）会拍到板外纯色或板缘
  亮线。覆盖多朝向机位用**圆柱内壁全景**：`CylinderGeometry(r,r,h,64,1,true)` +
  `BackSide` + `MirroredRepeatWrapping repeat.x=2`（镜像双幅，背面幅永不入镜就不必
  生成真 360° 图）；太阳方位用 `offset.x` 调到主视野内（先算方位角再逐机位目检）。
- 圆柱顶缘与天空的接缝：`scene.background` 用**采样自背景板实际像素**的竖直渐变
  canvas 纹理兜底（纯色会露平板边界；渐变 stops 直接吸取成图的顶部/中部色值）。
- 地面尽头与背景板的接缝：地面用**半径 ≥ 筒半径 0.9 的大圆盘**延伸过去 + `THREE.Fog`
  糊边，不要加异色远条带（会读成海平面）。雾的 near/far 别压到背景板太狠
  （far 小于板距会把落日糊掉）。

## 材质覆盖纪律（R5 补）

- **贴图必须覆盖到每一个面**，漏一个纯色件就破功：大地面、泥补丁、沙堆、碎石、
  远景盘全部进贴图清单。
- **近水平表面统一用世界空间顶视平面投影 UV**（uv=(worldX,worldZ)×scale），
  抛弃物件自带 UV：地面/补丁/沙堆共享同一比例尺，且锥体不再拉花。
  立面为主的物件（管件侧壁）保留自带 UV 调 repeat 即可。
- 补丁类想读出色差：同纹理 + 材质 color 压暗一号，不要换纯色。

## 全景融合四要素（S1E2 R6 实测）

1. **顶上天穹要闭合，但闭合不等于融合**：色带圆柱不封顶会露底；另加
   `SphereGeometry` BackSide 渐变只能覆盖空洞。圆柱顶缘是相机位置相关的曲线，
   带云纹的图片与另一张渐变球壳仍会硬切（R15 自由仰拍已复现）。在同一投影中
   做连续过渡，或制作同源完整全景；不要再声称加球壳即可任意仰角无接缝。
   `scene.background` 的 screen-space 渐变只能做最后保险，不能承担主覆盖。
2. **形变**：宽幅图绕圆柱 repeat=2 横向拉伸 2.3x。解法：用文生图**局部编辑把
   太阳/光晕从背景板抠掉**（暖光区保留），repeat 提到 4（形变 1.15x），太阳用
   程序化日轮+光晕世界锚定摆回（`fog:false`）——太阳唯一、方位可控、形变达标。
3. **天台感**：地面盘半径要**伸出背景筒壁**（r78 > r70）；前景与天际线之间加
   程序化中景剪影环带（远处料场/矮废墟，r40-55 暗色随机块）；接缝全靠雾糊
   （near/far 收到 30-100）。
4. **前后景边界感**=锐利程序面 vs 柔和 AI 面的接缝：靠中景剪影带+雾过渡，
   不要试图把 AI 图"调清晰"（512px/90° 的柔正是大气感）。

## 2D 图 → 3D 材质化（S1E2 R7 实测）

仿射/投影变换只是贴皮（图仍是平的）。材质化=从 albedo **派生会响应场景灯光的
立体信息**，技术分层与选型：

| 层次 | 技术 | 何时用 |
|---|---|---|
| 贴皮 | 平面/圆柱/顶视投影 UV | 兜底，无起伏 |
| **材质化** | 亮度 Sobel 梯度 → 切线空间法线图 | **默认该做**：泥地车辙/锈斑/布褶立刻吃光 |
| 2.5D | 深度估计 → 位移网格视差 | 近景悬空物需要真视差才考虑 |
| 真 3D | image-to-3D 生成网格 | 独立道具/装备与需转面的资产；沿用 [图像到三维资产](../build-image-to-3d/SKILL.md)，保留必要的交互结构 |

派生纪律（参考 `bio_armor_academy_s1e2/tools/derive_maps.py`）：
- 亮度梯度只能近似补充表面细节；基础色中的色斑、污渍、烘焙阴影不等于真实高度，
  不能把它称为深度重建。仅在纹理适合时试用，法线强度按材质分档
  （布料 ~1.2 / 沙 ~1.4 / 混凝土 ~1.6 / 泥地 ~2.2 / 锈钢 ~2.6），过强会像浮雕。
- 梯度计算边缘要 `wrap` padding，配合 MirroredRepeatWrapping 才不出接缝法线。
- MeshToonMaterial 支持 normalMap，不需要换 PBR 材质；法线图与 albedo 共用
  同一 UV/镜像设置。
- 程序化日轮/光斑用径向渐变 canvas 纹理（白热核→羽化缘），平涂圆盘会像贴纸。

- **中景过渡件别用悬浮色块**（R8）：方块+无光照 Basic 材质在天际线前读成
  悬浮假板；用压扁球体土丘 + 吃地面同纹理（顶视投影同比例尺）+ Toon 光照响应，
  读成远处料堆。共享材质必须**先定义后使用**——build 内顺序错了材质 undefined
  会静默落成默认白色。
## 翻车记录（S1E2 R4 实测）

- **锥体 UV 拉花**：圆锥/圆柱端盖贴图会拉成放射条纹（沙堆变帐篷）——旋转尖顶几何
  不贴图，保持色块。
- **贴图后过曝**：`map × color` 相乘，贴图材质 color 要压灰（如 #a39b90），不能留白。
- **Ark 图像 API 响应截断**：b64_json 体积大，`urllib` 会 IncompleteRead——必须重试
  3 次（E04 已有同款处理，新脚本别漏）。
- **seek 校验字节相等误报**：JPEG 编码器对同一画面偶有单个 8×8 块字节级不一致
  （真实像素差 ≤26 点）。校验应做像素容差比较（>16 差值的像素 ≤64 判过），
  见 S1E2 `render.mjs`。

## 顶部与材质复查（2026-10-09）

R15 最终视频与现行场景复查，证据在
`dula-story/episodes/bio_armor_academy_s1e2/storyboard/hybrid_audit_20261009/`。

- **限制仰角属于规避，不是接缝修复**：`clampSky` 将画面上沿限制为 13.5°，
  使正常检查帧看不见问题。诊断必须另做去限制的抬头、侧向、天顶检查，不能仅复看
  原来避开问题的镜头。读取实际相机位置、FOV 与顶缘覆盖范围。
- **同一表面的连续投影可以先解决硬边**：`scenes/ContinuousBackdrop.js`
  用视线与虚拟圆柱的交点保持低仰角原构图，高处将源图上方区域低通采样后连续
  过渡到天顶色，已作为 `RuinsDuskScene.applyHybrid({continuousSky})` 默认接入
  正片（R16）。`tools/probe_hybrid_sky.mjs` 输出四机位和 6 秒/180 帧并排证据。
  这不是完整 360° 云层生成，也不解决重复城市和近景视差。
- **fract() 计算的角度 UV 会在回绕方位画出一条竖直缝**（R16 实测）：屏幕空间
  导数在接缝处突变到 ±repeat，自动 mip 选到最糊一级，该列采样整图平均色，
  宽景天空下肉眼可见。修法：保留 fract，但对梯度做周期解缠
  （`d -= repeatX*round(d/repeatX)`），用 `textureGrad` 显式采样（WebGL2
  自动转 GLSL ES 3.00，无需扩展）。验收方法：同时间点对比新旧成片单列像素，
  肉眼巡图不足以发现 2px 亮列。
- **不能拉伸原图顶行补天**：源图的像素噪声会变成垂直条纹。试验中改为对上方
  一段图像做横纵双向平均，再渐变；连续颜色不等于云纹连续，重要仰拍仍需新素材。
- **世界 UV 必须使用完整变换**：R15 的 `planarUVWorld` 只算 Y 旋转和位置，
  `CircleGeometry` 原始顶点 z=0，转成地面后没有参与计算，测得远景盘所有 v=-1.04。
  用 `updateWorldMatrix` 后的 `matrixWorld` 变换顶点，再取世界 XZ，并包含父级和缩放。
  检查有面积的地面投影 UV 是否退化，不能只看“赋了 map”。
- **数据贴图不能走颜色解码**：当前通用 loader 对法线也设置 sRGB，需改为
  `NoColorSpace`；基础色保持 sRGB。法线/粗糙度/金属度是数值数据。
- **远近景明度也要统一**：发亮的无光照背景板和近黑的前景，会继续读成贴上去的
  舞台。用目标机位协调天空、环境光、远处雾和接触阴影；不靠全局曝光硬拉所有层。

自由仰拍改善只证明天空投影方案可行；最终选择完整全景、深度分层还是实体网格，
取决于实际相机运动和交互需求。不要用物件重建模型处理整张带天空的场景图来替代分层。

## 场景丰富化实战补充（2026-10-18《星屑战壳》R3）

- **材质全覆盖核查帧**：每场景出 establish/中景抽帧专查"还有没有大面积纯色
  平涂几何"——漏一个纯色件就破功，这条要做成例行抽帧而不是凭印象。
- **夜景灯光别浪费纹理**：纹理再多，灯光太暗等于没贴。新场景首帧目检调光
  （hemi/主光/补光强度按读感调），冷色场景 hemi .55 不够（实测要 1.1 量级）。
- **环形建筑的楣梁/帷幔切线对齐**：转角方位角 am 的切向是 `π/2−am` 而非
  `am+π/2`（后者在 am=π/4 处把梁横甩成径向）；几何转角件落代码前手算验算。
- **lookAt 前不许就地 mutate 方向向量**（`dir.multiply(sign)` 会污染后续
  复用），一律 clone。
- 道具密度清单参考：楣梁/帷幔旗帜（顶点摆动纯 t）/火盆圈/乱石堆（压扁球体
  贴碎石纹）/倒塌横卧柱段（两端断口贴面）/远景剪影带/岩浆 emissiveMap 脉动。

## 有顶内景（interior）混合场景（2026-10-18《星屑战壳》R9 星辉内殿）

天空圆柱/背景板那套只适用露天。宫殿类有顶场景：拱顶/穹顶本身做成带纹理几何
（桶形拱顶=CylinderGeometry 半管 BackSide），灯光按窗洞方向布置。验算与翻车：

- **半管朝向要旋转验算**：CylinderGeometry θStart=π 的半管经 `rotateX(π/2)` 后盖
  的是一侧不是顶——覆盖顶部的半管是 θ∈[π/2,3π/2]（该段 cosθ≤0，转到 +y）。
  验收=仰拍拱顶探针帧（zenith），不许只拍平视。
- **端墙封口要整圈**：CircleGeometry(thetaLength=π) 只是上半圆，下半用整墙箱体；
  透光门/窗面板贴在墙前面板内侧（+z 端 z 值要比墙前面板小，否则埋进墙体）。
- **拱肋 TorusGeometry 半环默认 XY 平面就是跨厅拱肋**，别加 rotation.y（转了变
  纵向贴顶弧，仰拍读成莫名其妙的两道贴面）。

## 水下场景顶封（2026-10-18《星屑战壳》R10 沉星海底）

水下无天空圆柱：顶部=从下方仰望的海面光幕大盘（CircleGeometry 法线朝下
rotation.x=+π/2，半径盖过最大仰角视野，透明加色水纹光斑，offset 纯 t 缓流）
+ god ray 锥形加色薄件垂挂缓摆 + 蓝绿 Fog 压远景（雾距近=水下能见度低，
兼当远景融合剂）。仰拍顶机位探帧验收不露平板边界。人物可读性靠正面补光
（别一潭死蓝：hemi 1.1+ 加 top/fill 双方向光）。

## 场景晨化/换时段与纹理共存（2026-11-05 星屑战壳 S1E1 R14）

夜版定型的混合场景改晨景（ep 侧 morningize 类皮肤）时，两套调色会互相覆盖：

- **顺序=applyHybrid 先、时段皮肤后**；皮肤层检测 `hybridApplied.length`，
  有纹理就**跳过 floor/far/stone 的 set/multiplyScalar 压色**（applyHybrid 的乘色
  已按纹理调定，再压=mud），只管灯光强度/雾距/天顶色。
- **背景板筒在就不加程序化天球**（球在筒内盖住背景板）；`scene.background`
  若被时段层覆盖，注意资产侧采样渐变兜底失效，用时段渐变顶。
- **资产侧夜景提亮会吹白晨版背景板**：applyHybrid 里 `brightness(1.4~1.45)`
  是给夜景图定的；ep 侧同口径 redraw 压回（canvas filter brightness ≈0.72 后
  重包 CanvasTexture 换 `sourceMap` uniform），zenithColor uniform 换时段色。
- **夜用剪影带/加色叠层**：剪影带（远景层次件）晨雾里太黑要提亮进霾；
  夜用加色（AdditiveBlending）沙痕层晨景必吹白，压 opacity 留形。

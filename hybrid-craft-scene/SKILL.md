# Hybrid Craft Scene（文生图 × 程序化 3D 混合场景）

程序化 3D 场景的"片场感"根因通常不是 3D 本身，而是**纯色零纹理 + 几何太规则 + 光太平**。
本工艺只把"皮肤"交给文生图：几何、绑定、动画、光影全部留在程序化侧，相机与交互自由度不变。

**参考实现**：`dula-story/episodes/bio_armor_academy_s1e2/`（`tools/gen_textures.py` +
`scenes/RuinsDuskScene.js` 的 `applyHybrid()`，2026-10-08 R4 验证）。

## 分工原则

| 归文生图 | 归程序化 3D |
|---|---|
| 材质纹理（泥地/混凝土/锈钢/布料） | 几何、UV、遮挡、碰撞 |
| 远景背景板（matte painting：天空/天际线） | 相机运动、角色动画、口型 |
| —— | 光影方向（纹理必须无方向性阴影，光影归灯光） |
| —— | 中近景道具轮廓（AI 纹理只提供表面细节） |

## 纹理 prompt 纪律

- 关键词：`无缝平铺材质贴图` + `正俯视/正视` + `均匀散射光` + `无强烈方向性阴影` +
  `无文字无人物` + `四方连续`。**纹理里烤进方向性阴影是最常见翻车**（和场景灯光打架）。
- 模型出图不是真无缝：Three.js 侧用 `MirroredRepeatWrapping` 镜像平铺，免接缝零后处理。
- 逐文件落 `source.json`（provider/model/prompt/sha256），生成脚本 skip-if-exists。

## 背景板纪律

- 一次生成"天空+天际线+太阳"整幅宽幅（如 2048×768），替换程序化天空渐变和剪影楼群；
  prompt 里钉死太阳位置（"画面左三分之一处"）和地平线高度（"下三分之一"）。
- 平面摆位后**用主相机逐机位检查太阳落点**——图里太阳在 23% 宽度处，平面不偏移
  根本不进画面；平面中心 x = 期望太阳世界 x + (0.5-太阳u) × 板宽。
- 板边缘之外：`scene.background` 用同色系**竖直渐变 canvas 纹理**兜底（纯色会露平板边界）。
- 地面尽头到背景板之间加暗色远条带 + `THREE.Fog` 把接缝糊进大气；雾的 near/far 别压到
  背景板太狠（far 小于板距会把落日糊掉）。

## 翻车记录（S1E2 R4 实测）

- **锥体 UV 拉花**：圆锥/圆柱端盖贴图会拉成放射条纹（沙堆变帐篷）——旋转尖顶几何
  不贴图，保持色块。
- **贴图后过曝**：`map × color` 相乘，贴图材质 color 要压灰（如 #a39b90），不能留白。
- **Ark 图像 API 响应截断**：b64_json 体积大，`urllib` 会 IncompleteRead——必须重试
  3 次（E04 已有同款处理，新脚本别漏）。
- **seek 校验字节相等误报**：JPEG 编码器对同一画面偶有单个 8×8 块字节级不一致
  （真实像素差 ≤26 点）。校验应做像素容差比较（>16 差值的像素 ≤64 判过），
  见 S1E2 `render.mjs`。

# 漏检学习与回测

本 skill 的改进单位是“能把注意力引向有效证据的观察方法”，不是越来越长的
禁令或某个角色的专用比例。用户后续反馈是重要来源，但不是唯一来源：
自主复看、镜头转换、修订回归和同类新片段都可揭露漏检。

## 每个漏检保留什么

在 episode 的巡检记录旁保存案例。写清：

- **原始判断**：哪个版本、哪次记录、哪些角色/时间/视图；当时结论是什么。
- **后来发现**：谁发现、何时发现、具体可见事实与证据。原片当时已有的问题与
  新修订引入的退步分开；后者不能伪装成旧版漏检。
- **漏检环节**：没取到有效画面；取到了但没看该区域；看了但判断错误；
  被改动参数或已有结论引导；发现了却错误降级；或修复后没查相邻副作用。
- **注意提示**：下次在什么情形下，沿哪条结构/动作关系看，什么证据能支持判断。
  示例：“沿耳顶到耳垂，再到颌后缘和颈根”，比“耳朵检查更仔细”可执行。
- **反例和边界**：什么合理设计不应被误报；修复不足和修复过量分别是什么。
- **回测**：旧片能否复现问题；另一段是否适用；修复是否有效、有无新退步。
  标明 `未测试 / 带提示复现 / 拓展片段试用 / 跨片段有支持 / 不适用或误报`。

先修正文档中已有提示的表达和触发位置，合并同类提示；确有新关系才增加维度。
若问题来自执行漏项，优先修覆盖与证据要求，不继续复制同一句提醒。
无收益的提示要缩小范围或删除，避免清单噪声让主问题再次被淹没。

## 怎样试用而不自我暗示

1. 对新片段先保存未标注原图/连续画面，使用通用维度独立写观察，再读该片段的
   历史问题单或实现说明。已在上下文里见过答案时，如实标为带提示复查。
2. 用旧失败片证明提示能指向正确的关系；用邻近正常片或已认可性质检查误报。
   参考不足或风格不同就记录不确定，不能硬造一个“正常标准”。
3. 下一处不同时间/动作/角色继续试用，检查是否能迁移。新时间点不自动等于盲测，
   也不自动证明已经提高了发现率。
4. 跟踪实际修复：找对问题但修法失败，分别更新判断与实现记录，不能一起报成功。

## 怎样看是否减少人工迭代

按可比的片段或版本记录：

| 观察量 | 含义 |
|---|---|
| 交付前自主发现并修复的严重问题 | 必须有用户提示前的观察记录及修复证据 |
| 后来补充的严重漏项 | 按问题合并计数，避免拆成许多小项抬高成绩 |
| 同类复发 | 已有可执行提示、适用情形仍漏掉，查执行或提示设计 |
| 修复引入的新问题与误报 | 不能为“发现更多”而乱改已认可的性质 |
| 用户纠正负担 | 用户是否仍需逐帧截图、重复指出同一关系 |

没有完整真值就不计算总体召回率。用户没有反馈不代表无漏项；少查镜头、换更容易
的样本、把严重问题降级也不能算进步。短期先看个案，证据累积后再谈趋势。

## 启动案例：当前已有的漏检类型

以下来自既有记录，属于**带提示整理**，不计为新 skill 自主发现或修复成功。
详细画面与时间留在原 episode，skill 只保留可迁移的注意提示。

| 触发情形与旧盲点 | 下次注意提示 | 反例/过修风险 | 当前证据状态 |
|---|---|---|---|
| 发丝变细、接缝减少后，仍漏掉头套感 | 正常尺寸看颅顶与后脑大形，再沿发根—主束—发梢检查宽窄、负空间、耳后/后颈收束；把细线暂从注意中移开 | 光滑短发可以是设计；不能把所有发型拆成乱翘细束 | 已有用户反馈与当前画面复查，未有新修复验证 |
| 脚点稳定后，误把走路当作自然 | 连看提步前、换脚与收步，追踪髋—胸—头以及持械手的相对变化；看最后一步如何传递制动力 | 持重物、受伤、警戒可限制摆臂；不能一律加大摆动 | 既有步态帧列支持诊断，正常速度整体观感和新修法待验 |
| 局部眼睛/下颌改过，整脸仍不协调 | 回完整头颈，沿眼线—面颊—下颌—耳根—颈根检查比例与连接；区分连续无缝和关系正确 | 直下颌、尖下巴本身不是缺陷，不能普遍磨圆 | 既有角色审美复盘明确记录多次用户补漏 |
| 手臂与光效在动，身体发力仍空 | 连看支撑、髋胸肩传递、末端路径、防守者脸和身体响应，再看余力 | 魔法/刻意克制也要有意图依据，不能给每个动作套同一大幅预备 | 当前战斗研究支持诊断，未有新动作修复验证 |

## 首次试跑暴露的取证错误

2026-10-20，在 `stardust_clad_s1e2` 的局部试跑中，主代理发现旧研究把
128–132秒计划为眼神样片，而最终 MP4 在128–131.8秒主要展示地面导火槽和腿。
这属于**审查计划错误**，不能因此断言插入镜头本身拍错。实际脸部近景在132秒后。
旧计划保留并追加纠正，记录见该集 `storyboard/character_attention/r27_trial.json`
的 M01；没有将这次发现改写为以前已知道。

新增提示：从剧情 cue 选窗后，先确认观察对象在画幅中、时间覆盖足够，再开始
维度判断；不适用时主动移到邻近实际镜头。本例已补看132–137秒，证明选窗错误
得到纠正，**不证明表情已经改善或整套 skill 已能独立发现所有问题**。

## 新集实验：查出问题不等于做出更好的角色

2026-10-20，`stardust_clad_s1e3` 自主制作实验出现两类执行漏项：

- 重搭身体后，近景面部有更多明暗，但全身的战壳、腰部和肩臂关系退步。主代理
  经多轮画像修订才充分回到完整人物与上一集对照。这里原来就有“肉体感不等于
  露肤”“保留已认可性质”的提示，问题在执行顺序，不能假装是新增概念解决了它。
  新提示：代表性试片必须同时对照已接受基线，不只对照本次更差的原型。
- 救援接触点靠近后，仍漏掉获救者落回已损坏桥板的后果。后续开放复查看出，
  将破坏限定为前半桥面、落点改到完好的后半桥面，重新检查完整救援过程。
  新提示：沿动作追到状态变化之后，再看下一动作的支撑与道具关系。

反例：故意坠落、受控悬空和失衡可以成立，不能强行把所有脚放回地面；衣甲简化
可以是设计，但不能自行把用户认可的系列造型改成简陋替身。

该集保留了原型、修订与失败记录；主代理在查看过的画面中仍判断新片整体未超过
接受基线，距参考的形体、发型和表演明显有差距。局部修复不构成整套工艺成功。
具体证据、未解决项与查看方式放在该集 `storyboard/character_attention/`，
不可把本案例描述为无人介入即可稳定达到商业动画质量的证明。

# Stage Musical（舞台演出专项）

剧院演出类内容区别于日常场景的根本点：**观众视角是叙事本体**——镜头是观众席里的
一双眼睛，不是到处飞的航拍器。本 skill 覆盖舞台积木搭建、第一排 POV 运镜、演唱
表演、歌谱结构与灯光叙事。口型链路本身归 [song-lipsync](../song-lipsync/SKILL.md)，
音乐生成归 episode-scoring，本文件只管舞台与观演关系。

本 skill 放 `dula-skills/stage-musical/`；产物归 `dula-story/episodes/<episode>/`
（场景类 `scenes/<Name>StageScene.js`、走位/灯光进 `config/`、谱面进 performance.js）。

## 何时用 / 不用

- 用：音乐剧、演唱会、汇演、演讲、课堂发表——一切"台上有人演、台下有人看"的内容。
- 不用：外景/室内日常（用 scene-designer）；纯打斗调度（fight 系 skill）。
- 判断信号：剧本里出现"观众反应镜头"或"报幕/谢幕"，基本就是本 skill 的场景。

## 舞台积木（craft3d 程序化，全程序零贴图资产）

全部用 canvas 纹理 +  primitives，纪律同 craft3d 场景积木（RooftopNoonScene 参考实现）：

| 积木 | 做法 | 关键数值/翻车点 |
|------|------|----------------|
| 台面木地板 | `BoxGeometry` 台体 + canvas 板条纹理（顶视 planar UV） | **板条方向顺台口**（平行于台唇线，垂直=一眼假）；板宽 0.12–0.18m，伸缩缝暗线 5% 明度差 |
| 台唇 | 台体前缘一条 4–6cm 高的沿口盒 | 是相机的绝对边界（见 POV 纪律）；台裙（台体正面）用深一号纯色 |
| 主幕布 | 高段数 `PlaneGeometry` 顶点正弦褶皱（x 向 6–8 个周期、振幅 8–12cm）+ 顶点色深浅（褶谷深褶峰浅） | 褶皱是几何不是纹理（纹理褶皱拉远即平）；丝绒感=深红底色+顶点色，别加高光 |
| 侧翼幕 | 左右各 2–3 片同款褶皱面片，朝台内斜 20–30° 排出门 | 翼幕之间是上下场通道，谱面走位从门进出 |
| 脚灯排 | 台唇上一排小半球壳（`SphereGeometry` 半切）朝上 | 视觉上只是亮壳；照明贡献用一排朝上弱 PointLight 或并入主光方向，别真的每颗一盏灯（性能+阴影噪声） |
| 追光 | `SpotLight`（angle 10–16°、penumbra .3-.5）+ 地面/演员身上的亮斑圆片（假光斑优先） | 体积感可选：锥内一片 additive 雾薄片；追光=注意力导演（见灯光叙事） |
| 观众席剪影 | 前两排头顶轮廓：近黑椭球排（发球体 scale 压扁）在画面下缘 | 近黑不纯黑（#0d0b10 档）；剪影给"你在剧场里"的尺度感，也是前景遮挡构图件 |

## 第一排 POV 纪律（核心）

相机=观众席第一排坐姿观众的眼睛。全部运镜从这条纪律派生：

1. **机位**：相机 y=观众席地面 +1.2m 处（坐姿眼高 1.15–1.25m）；x 在观众席中线附近，
   z 永不越过台唇平面往台上去。仰角由台高差自然产生（演员胸口≈台高+1.2m）。
2. **低仰角 5–12°**：lookAt 台中央演员胸口；仰角>15° 读成"趴在地上"，<3° 读成
   台上机位（穿帮）。
3. **永不切台上视角**：不反打、不侧台、不俯拍——一切"切镜"都是观众席内的转头
   （yaw ±25°）或坐姿微调；要表现"后排视角"只允许**拉高座位**（后排水准 = 眼高
   +0.4m/排、仰角渐平），不许上台。
4. **推拉幅度小**：±0.5m 内；镜头感主要靠**追光移动和演员走位**制造，不靠运镜。
   观众的"呼吸感"= 机位 bob ±2mm 极缓正弦即可，多了就是手持纪录片。
5. 观众席剪影（前排头）永远在画面下缘 5–10%——它是"我没上台"的持续证据；
   演员走到台唇时头顶被前排剪影切掉下缘是允许的（近大远小的诚实）。

## 演唱表演工艺

- **持麦手型**：麦=细长握持件，锚捏合区（拇指腹-食中指第一节），不锚掌心——
  口径与数值直接引用
  [direct-animation-craft/references/contact-and-hands.md](../direct-animation-craft/references/contact-and-hands.md)
  的捏持锚点节（签/筷同型）；递麦/换手的交接帧单独抽近景目检。静态麦架=道具
  状态机多一个"插回架"状态（放置三律同样适用）。
- **走位图**：台位标记用舞台语义不用坐标——中央（C）/台左（SL）/台右（SR）/
  台唇（lip）/翼幕门（wing）；谱面事件按台位点名（`{Event:Move|...|spot=lip}`），
  坐标换算进 config。演员演唱时走位少而准：主歌站桩、副歌上台唇、过场才横穿。
- **AB 段对比**：主歌=收（手贴身、小步、看地面/看麦）；副歌=放（张臂、上台唇、
  看向观众席深处）。对比靠幅度差制造，不靠速度差。
- **唱砸/紧张表演**（音乐剧常用情绪点）：眼神飘忽（headYaw 小幅度快速换向
  2-3 次/秒级收敛）、身体僵（次级运动全关、breathing 停 1-2 拍）、**追光迟疑**
  （追光晚 0.3-0.5s 才跟上走位）——技术位也能演戏，这是舞台独有的表演层。

## 歌谱结构与时长模板（≤3min 总预算）

| 段 | 时长占比 | 功能 | 舞台动作 |
|----|---------|------|---------|
| 开场（报幕/静场） | 10–15% | 建场：幕启/灯亮/观众剪影入画 | 演员上场到 C 位，追光就位 |
| 主歌 A | 20–25% | 叙事铺陈 | 站桩 C/SL，脚灯+面光 |
| 副歌 B | 20–25% | 第一次情绪释放 | 上台唇，追光全开 |
| 过场（间奏/桥段） | 10–15% | 换场/换装/情绪转折 | 走位横穿或灯光独奏（演员暗场） |
| 主歌/副歌再现 | 20–25% | 升级再现 | 走位组合变奏 |
| 收尾（谢幕） | 5–10% | 鞠躬/幕落 | 回 C 位，追光收拢，脚灯最后灭 |

口型：人声轨先行（歌先于画面锁定时长），程序角色口型走 song-lipsync 链路
（人声分离→DTW 逐字对齐→视素轨）；本 skill 不加第二张口型通路。

## 灯光叙事

- **追光=注意力导演**：观众看哪由光斑决定，不由镜头决定。追光移动要"有理由的
  迟滞"（跟走位慢 0.2-0.4s 是活人操作感；完全同步=机器人）。
- **色温/颜色随情绪段落表**（写进 config，随谱面段切换、边界 0.5-1s 过渡）：
  主歌暖白（≈4300K 档）、副歌全亮暖金、桥段压冷蓝（≈7000K 档+降脚灯）、
  唱砸/紧张段追光收缩（angle −20%）并偏冷。色突变必须有过渡帧，硬切色温
  读成事故灯。
- 观众席永远暗：剪影近黑、只借舞台溢出光勾头顶轮廓（rim 即可，别给面光）。

## 验收

### 人与舞台共用光影（2026-10-28《星辰马戏团》开工试验）

用户要求人物、场景的光影变化一体化。将灯光关键点锚到 `.story` cue，由同一个
绝对时间状态驱动脸、衣服、地板、钢琴和幕布；每块接收面可以有不同响应，
不能把所有像素统一曝光当作空间光照已成立。关键光变化须看脚底接触暗部与道具投影。

固定姿势绘画试验可先验证同框照明：以整幅同框原画建立统一笔触/光向，再由生成式
暗端点提取平滑照明比，始终保留同一张母版的几何与细节，避免直接淡化两张重绘人物。
共享工具在 draw-over-animation 的 `assets/scene-light-score.js` 与
`assets/painted-light-field.js`，范围见其 `references/executable-pipeline.md`。
本例仅通过22秒固定姿势的光影试验（660帧、26次取帧一致检查），没有验证移动追光、
人物行走、变化投影或声画表演；这些必须另做连续动作试片，不能由静帧美术批准代替。


- 接入 `episode_gate.py`（direct-animation-craft 总验收链）：接触探针 trace +
  逐拍近景审片组 + flicker（幕布褶皱与灯壳是 alpha/共面风险件，进 watch 区）。
- **舞台几何进 contact contract 障碍物清单**：台唇沿、麦架、台阶、翼幕门柱——
  演员走位路径不得穿台唇/麦架；观众席剪影是相机前景不是障碍，但要进相机安全
  距离核算（不穿前排头顶）。
- POV 纪律自查：全片抽帧确认相机 z 从未越过台唇平面、仰角全程在 5–12°、
  观众席剪影全程在画面下缘。这三条可以写成一个十行的镜头探针（相机位姿纯函数
  断言），进 contract 的 camera 段。

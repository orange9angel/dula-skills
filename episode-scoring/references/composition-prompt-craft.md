# 大模型作曲 prompt 工艺（Seed-Audio 1.0）

> 定位：让 Seed-Audio 一条 prompt 出的 BGM 从"氛围底床"升级到"有作曲感的配乐"。
> 目标艺术水准对标久石让式动画配乐——**学的是工艺特征不是旋律**（禁止抄实际曲目）。
> 首用：cat_leads_e06_cat_model BGM v2（2026-09-05）。

## 核心认知

Seed-Audio 的 text_prompt 上限 3000 字符，理解自然语言的音乐指令。**它听得懂
曲式、配器、调性、动态、速度这些专业词，但你不写它就按最平均的方式出曲**。
配乐"平"的两大根因（都是我们自己造成的，不是模型上限）：

1. **"结构平稳起伏小"这种保守要求 = 平曲**（E06 v1 实测翻车）。
2. **"激烈/动感"这种平词 = 平曲**（E04 beatcut demo 翻车）。

## Prompt 解剖（按这个结构写，顺序即权重）

```text
[时长+场景定位] 生成一段XX秒的XX系动画配乐，场景情绪是……
[曲式] 曲式：0-Xs ……；X-Ys ……；Y-Zs ……（每段写清谁进谁出、力度变化）
[主题] 主题动机：简短歌唱性旋律（4-6音），先独奏呈现，后由弦乐展开
[调性与和声] C大调为主，借用IVmaj7/ii-V增加暖意，可短暂转小调色彩
[配器] 分层点名：钢琴独奏 / 弦乐群托底 / 木琴点缀 / 双簧管或长笛独奏高光
[动态] 动态范围要大：开头pp，中段渐强到mf，结尾回pp渐弱收束
[速度与节奏] 自由速度感（rubato），约XX BPM，无鼓组（除非剧情要）
[留白] 乐句之间留呼吸空隙，不要填满
[禁止] 无人声，无电子音色，无鼓组重拍，无突然爆音
```

### 久石让式治愈配乐的工艺特征（写 prompt 时的 checklist）

- **动机优先**：一个 4-6 音的歌唱性短动机，重复+变奏贯穿，而不是流动的和声垫。
- **配器分层进入**：独奏乐器先出主题（钢琴/木琴），弦乐群后进入托底，
  高点用木管独奏（双簧管/长笛）提亮——"分层进入"本身就是叙事感。
- **动态对比**：pp → mf → pp 的大弧线比"全程平稳"重要得多。
- **留白**：乐句间的空隙是治愈感的一部分，"不要填满"要写进 prompt。
- **和声暖意**：大调 + IVmaj7/ii-V 借用和弦，偶尔小调色彩做对比。
- **rubato**：自由速度感，避免机械节拍器感。

## 曲式映射剧情弧线（做法）

把剧集的情绪弧线直接翻译成曲式段落，时间点尽量对齐剧情转折：

| E06 实例 | 剧情 | 曲式段 |
|---|---|---|
| 0-10s | 开场悠闲 | 钢琴独奏动机 pp |
| 10-25s | 摆姿势/蝴蝶搅局 | 弦乐进入，木琴点缀，渐活泼 |
| 25-45s | 追逐/树荫闲谈 | 主题在弦乐上展开，mf |
| 45-60s | 睡颜/揭示/收束 | 弦乐退场，钢琴再现动机，渐弱 |

## 验收（客观指标 + 听感）

1. **onset 数**：跑 `beatcut-edit/scripts/beatcut.py` 的 onset 检测，60s 少于
   50 个 onset = 太肉，换一版。
2. **能量曲线**：每秒 RMS 必须有起伏层次（pp/mf 对比），一条直线 = 单调，
   直接判死。
3. **听感三段抽查**：开头/中段高点/结尾各听 5s——开头要听得清动机、
   高点要有厚度、结尾要收得住。
4. **不对抗对白**：正片混音后抽查对白段，旋律线不糊台词（糊了就降
   bgmVolume 或在 cue 里让音乐在对白句前减弱）。

## 选优纪律（三版选一）

主题动机的旋律质量是概率采样出来的，prompt 控制不了单个音符。正式集流程：
同一 prompt 生成 3 版 → onset/RMS 初筛（参照「验收」）→ 人工听动机记忆点
定稿。E06 v2 即按此精神生成（一次达标属运气，流程上仍走三版）。

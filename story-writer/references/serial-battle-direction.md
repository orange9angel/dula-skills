# 连载战斗剧导演工艺

用于持续闯关、救援、追击与阵营冲突的连续剧。长剧节奏由因果、人物关系和后果
的积累决定，不以单集分钟数判断。一场战斗可以跨集；短集也应留下足够的观察、
决定、反应和余波。本文是从剧情资料研究提炼的创作方法，不是已完成的逐镜、
配音或配乐分析，也不构成某部成片的质量验收。

## 1. 先决定这一集改变什么

同时写下三个目标：本轮行动要完成什么、人物关系要改变什么、整段旅程要保住什么。
例如“守住渡口 / 接受同伴接替 / 让下一批伤员通过”。战斗结果服务这三个目标，
不必都归结为击倒敌人。局部失败也可以完成一次关系变化。

每集选一个主要变化，分配必要篇幅：

| 段落 | 观众应获得的变化 | 常见失效 |
|---|---|---|
| 战前生活与关系 | 看见值得保护的具体人、物或约定 | 空镜很长，人物仍只有口号 |
| 遭遇与试探 | 知道双方当下要什么，看到一条作战规则 | 报完姓名立刻轮流放招 |
| 反制与损失 | 旧办法失效，失败留下可用的信息和代价 | 同一次扑击反复播放，状态不变 |
| 观察与选择 | 角色决定承担哪一种风险 | 突然增加未铺垫的力量 |
| 执行与余波 | 选择改变结果，伤势和关系进入后续 | 爆炸结束后一切恢复初始值 |

这些是因果检查点，不是每集必须齐全的五段模板。接战集可以停在新规则揭示后，
但应先完成一个可感知的事件；收束集可以承接上集的观察，直接付诸行动。
既不为凑时长拖长静止，也不为单集闭合压掉重要反应。

## 2. 把信念写成行为限制

给主要对手建立一张简短导演卡：

- **眼下诉求**：他要挡住谁、取走什么、保护什么？目标能否在画面中定位？
- **判断依据**：什么经历或利益使他相信当前做法？不必立即完整交代身世。
- **行为界限**：他肯牺牲谁、拒绝什么、在什么情况下会迟疑？
- **战斗表达**：打法怎样体现他的判断，又留下怎样的局限？
- **失败选择**：败退、守约、报复、求援、坚持错误，哪一种符合此人？

人形敌人应有人的注意力、呼吸、疼痛和判断，不能只替换怪物网格却保留咆哮、
扑咬与兽类受击节奏。武器、步态和声音也应按新角色重做。
但“像人”不等于善良，更不等于都要悲惨身世和临终悔悟；职责、野心、偏见、
恐惧、忠诚和私人利益都能支持冲突。理解其选择不替他免除伤害的责任。

信念台词需要一次行动兑现。例如相信“只有强者值得救”的守卫，在混战中真的
放弃一个失去战力的同伴；主角则放弃进攻窗口去接住伤者。观众因此看见两种
价值观付出的不同代价。若删去宣言仍看不出差异，先改行为。

允许表面行动与隐秘意图不一致，但要先留下可回看的证据。隐情揭示后，应改变
观众对前面某个动作的理解；不能用一段身世旁白强迫观众推翻毫无伏笔的事实。

## 3. 招式是可观察的规则

主要招式明确：发动征兆、覆盖范围、有效条件、限制、失败后果。只将本轮破解
所需的部分呈现给观众，避免讲解整套设定。大招的名称、图形和声音保持辨识度，
升级优先改变使用方法、时机、对象或协作关系，再考虑增加新能力。

一次有效的破解通常能追溯：**看见异常 → 形成猜测 → 试探付出代价 → 修正理解
→ 承担风险执行**。不要求固定失败次数；已经知道规则的角色也可以直接行动，
但信息来源要成立。对手不负责主动讲出自己的漏洞。

原创示例：

1. 守卫挥出高位亮弧，盾挡住了亮光，持盾者的腕扣却断裂。
2. 同伴看到石阶上有两条深浅不同的划痕；第二声链响比亮弧晚半拍。
3. 他过早封住高位刀路，仍被贴地回刃逼退，确认不是单纯速度问题。
4. 持盾者主动留出上方空隙，把第一道攻击交给同伴，自己保护受伤的下臂。
5. 第三人封住退路，原有招式才得到有效窗口；胜后腕伤和断扣仍需处理。

线索要实际拍到、听到。不能只在导演文档写“他发现破绽”，成片里却靠一句解说
跳过观察。画面骗角色可以，剪掉解题所需信息骗观众则需要明确的叙事理由。

## 4. 对白、表情与动作共用一个决定

给关键台词标注：**此刻想改变谁的行为 / 不愿说出的部分 / 说完采取什么动作 /
对方如何接收**。威胁、试探、请求、拒绝、承诺都应有对象，避免轮流面向镜头
陈述主题。战斗中的长句安排在对峙、喘息、遮蔽、距离拉开等真实窗口内；不要让
正在高速飞行的拳头停数十秒等独白结束。必要时跨镜延续声音或明确使用主观时间。

一条台词不必只对应一个表情。可先注意伤口，再避开同伴目光，最后决定求助；
嘴上的逞强与手指松脱可以同时发生。听者也要经历“听见—理解—回应”，反应可以
是视线停住、重新握紧、收回半步，未必要另加台词。先选择主动作，再安排细节，
不要把每句都堆成皱眉、眨眼、点头、握拳的固定组合。

招式名的演绎属于人物决定的终点：呼吸准备、重音、停连与出手必须相互支持。
先听实测配音，再决定蓄力与释放的长度。喊完招到命中之间若有等待，应有明确的
空间或战术原因。命中镜头要看得见双方关系；特写、速度线和光效不能替代接触。

## 5. 把声音写进因果

声音总导演按 [direct-episode-audio](../../direct-episode-audio/SKILL.md) 执行；
此处只交接叙事职责，不另设生成后端。

- 环境声建立空间和连续性；关键链响、脚步或呼吸可以成为观察线索，后续破解
  必须复用同一种声音关联。不要给不存在的动作铺“好听的音效”。
- 大招前的收声要服务注意力：可让配乐退出，保留紧握、呼吸和环境底，随后由
  出手与接触建立强弱差。静场不等于无理由地掐断整个世界。
- 角色或信念的音乐动机可以在不同关系下重现；是否变奏由剧情决定，不能每次
  报招都从头铺一段完整高潮。对白、发现线索的音效和命中优先级要逐段明确。
- 战后保留身体后果的声音：短促吸气、甲片重新扣合、迟疑的脚步。胜利配乐不要
  抹去本应被感知的疼痛或未完成的救援。

给声音部门的交接记录包括“此声音让角色/观众知道什么”和实际画面锚点。声画
共用 `.story` 时序；最终混音后再验口型、招名重音、接触和余响，不能沿用旧音轨
的通过记录。保护已认可音乐，只有用户授权的范围内才调整或更换。

## 6. 跨集兑现与不同关卡

结尾先交付一个局部结果，再打开一个具体问题。可以是“伤员已渡河，守卫改变了
水位，留下的人必须另找出口”；不要总在招式命中前切黑，也不要用下一集预告
替代本集应有的余波。续集开头尽快兑现上一集承诺，回顾只保留重新定位所需信息。

每个关卡至少在战斗规则、对手目的、空间使用、主角所付代价中形成有意义的区别。
可以有追击、谈判、营救、分队掩护、失败撤退和战后修复，不必全是擂台单挑。
“换颜色—受伤—喊信念—同伴加力—敌人悔悟”不能作为连续宫殿的统一模板。
并非每宫都需要完整身世，也并非每宫必须跨集。

系列圣经记录本集留下的伤势、装备状态、知情范围、队伍位置、欠下的承诺及下一次
兑现窗口。战术线索和长期伏笔分开管理：前者可能当集回收，后者可沉默数集。
不能为了伏笔冷却规则，禁止角色利用刚刚看见的破绽；也不能靠每集复述维持悬念。

## 7. 审片问题与返工入口

| 问题 | 看什么证据 | 不成立时先改哪里 |
|---|---|---|
| 为什么非打不可？ | 明确目标、阻碍和至少一次选择 | 故事动机与场景空间 |
| 两个人的信念有什么区别？ | 他们在同一压力下做出的不同动作 | 行为与代价，再改台词 |
| 反击为什么现在能成功？ | 可回看的线索、先前尝试、此次变化 | 因果与战术，不先加特效 |
| 人物真的在交流吗？ | 注意对象、听者反应、接话后的变化 | 表演导演与实际运行通道 |
| 大招有重量吗？ | 蓄力、双方接触、受击恢复、空间后果 | 作画监督、镜头和声画时点 |
| 这集值得看，下一集值得等吗？ | 本集改变和具体未决行动 | 集界与余波篇幅 |
| 下集仍像同一段旅程吗？ | 伤势、道具、位置和知情状态持续 | 系列台账与运行时状态 |

先审一个包含观察、决定、出手与余波的连续片段，再推广到全片。文档写了不等于
viewer 执行了；关键帧漂亮不等于动作连续；技术门禁通过不等于达到商业动画水准。
报告区分剧情方案、已执行表演、实看画面和实际听过的音轨，不夸大资料研究或验收。

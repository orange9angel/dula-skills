# 动漫表情符号化系统

表情符号（汗滴、爆筋、豆豆眼、黑线脸……）是情绪事件的图形速记：
由情绪触发、短时出现、准时退场，**不常驻**。缺了这套符号，三维角色的脸
再精致也只是"会动的偶"，不是动画片（bio_armor_academy_s1e2 R21 复看
确认的缺口：全片符号为零）。

## 载体取舍

- **face canvas 叠加层**：在 paintFace 类工艺里，符号画在同一张脸 canvas
  的上层（五官全部画完之后叠加）。零深度冲突、随头型 UV 贴合零成本；
  代价是符号不能伸出头部轮廓，且随 UV 变形。
- **billboard 面片**：独立 PlaneGeometry 挂 headGroup，可伸出轮廓外；
  代价是要处理朝向与深度排序。
- **推荐分工**：不伸出轮廓的小符号（汗滴/爆筋/脸红/黑线/青筋）一律
  canvas 叠加；必须出轮廓的（大汗滴、蒸汽团、气泡）用 billboard 面片。

## 符号清单与语义

| 符号 | 语义 | 载体 | 停留 |
|------|------|------|------|
| 汗滴（小） | 尴尬、慌张 | canvas | 0.6–1.0s |
| 大汗滴（出轮廓） | 无奈、尴尬升级 | billboard | 0.8–1.2s |
| 爆筋十字 | 愤怒、被激怒 | canvas（额头/太阳穴） | 0.5–0.8s |
| 眼白全白 | 震惊、晕厥 | canvas 换眼形分支 | 0.3–0.6s |
| 豆豆眼 | 呆滞、无语 | canvas 换眼形分支 | 0.5–1.5s |
| 脸红斜线 | 害羞、窃喜 | canvas | 整个情绪段（1–3s） |
| 黑线/阴影罩脸 | 阴沉、极度无语 | canvas | 0.5–1.2s |
| 大笑眼（∩ 上拱弧） | 大笑、开心 | canvas 换眼形分支 | 跟随台词段 |
| 青筋 | 用力、强忍 | canvas | 0.4–0.8s |
| 蒸汽/气团 | 生气冒烟、羞愤 | billboard（可叠粒子） | 0.6–1.0s |

## 绘制配方（canvas 层）

坐标基于 512×512 逻辑脸 canvas，与 paintFace 同一坐标系
（眼心 `(256±dx, eyeY)`，本集 `dx≈90–95`、`eyeY≈242`）。
所有符号在五官绘制完成后叠加；符号状态并入 `draw()` 的缓存 key，
否则 key 不变、符号不重绘。

- **汗滴**：水滴路径 `moveTo(0,-14); bezierCurveTo(9,-2,10,7,0,12);
  bezierCurveTo(-10,7,-9,-2,0,-14)`，填 `#bfe3f2`，(-3,-5) 处 r=2.5
  白点高光，描边 `#7fb6cf` lineWidth 1.5。定位太阳穴外侧
  `(256+side*(dx+70), eyeY-60)`；多滴沿颊边下行错位 14px。
- **大汗滴**（billboard）：同上路径放大 2.2 倍，面片 0.06×0.06m，
  从鬓角出发 0.9s 内下滑 0.05m、alpha 1→0。
- **爆筋十字**：两条交叉圆角粗线（互成 80°、长 26px、lineWidth 6、
  lineCap round），四端各加 6px 短刺；色用角色线色调红（如 `#7a3a3c`）。
  定位额头侧 `(256+side*(dx+55), eyeY-75)`；可大小双筋错位 18px。
- **眼白全白**：换眼形分支——不画虹膜/瞳孔/高光，眼形 clip 内填
  `#ffffff` 加顶部 15% 浅灰渐变，保留眼框线；配眉毛上扬、嘴 jaw>0.5。
- **豆豆眼**：换眼形分支——双眼各一个实心椭圆（r≈6×9），色 `#392b31`，
  无高光无边线；配一条平嘴线。
- **脸红斜线**：双颊各 3–4 条 45° 平行短斜线（长 16px、间距 7px、
  lineWidth 3），色 `#e89a90` alpha 0.8，定位 `(256±dx, eyeY+55)`。
- **黑线罩脸**：额到眼上半区 5–7 条竖直平行线（间距 6px、lineWidth 2.5），
  色 `#2c2730` alpha 0.55，上叠一层 alpha 0.25→0 的自上而下深色渐变罩。
- **大笑眼（∩）**：换眼形分支——整条眼形替换为上拱弧
  `moveTo(-40,4); quadraticCurveTo(0,-26,40,4)`，lineWidth 6.5、round cap。
  **与眨眼严格区分**：眨眼是眼皮从上往下盖住固定虹膜（openness 缩小），
  笑眼是删除虹膜、整眼换弧线——两者永不同时出现。实现上 smile>0.5 时
  把闭眼分支改画 ∩ 弧而非平直闭眼线（本集 paintFace 已按此分支）。
- **青筋**：太阳穴到发际 2–3 条 Y 形分叉折线，lineWidth 2，用角色线色。
- **蒸汽团**（billboard）：3 个重叠圆（r 8/11/9）组成云团，
  色 `#f5f2ee` alpha 0.9；面片从鬓边/头顶出发 0.6s 内上升 0.05m、
  scale 1→1.3、alpha→0。

## 出现与退场时序

三段式：

1. **弹入 2–3 帧**：scale 0→1.15→1.0 的回弹，与情绪事件同帧触发；
2. **停留**：按上表时长；
3. **退场**：情绪类淡出 0.15–0.3s（globalAlpha）；震惊类（白眼/豆豆眼）
   硬切进硬切出。脸红例外——随情绪段常驻，段尾淡出 0.3s。

## 载体工程细节

- **billboard 面片**：`PlaneGeometry` +
  `MeshBasicMaterial({map, transparent:true, depthWrite:false})`，
  `renderOrder` 排在头壳之后；挂 headGroup 内固定局部坐标
  （随头部运动，不写世界坐标）。
- **朝向**：每帧 `lookAt(camera)` 全 billboard，或仅正面扇区显示——
  headYaw 超过 ±60° 时 0.1s 淡出隐藏，避免侧脸看到贴片横穿。
- **boil 协调**：canvas 符号随脸纹理走，不参与 BoilSystem；billboard
  面片若进 BoilSystem，amplitude 减半到 ≤0.002，否则符号边缘抖成脏线——
  更稳的做法是符号面片一律不进 boil（boil 参数见
  [handdrawn-style.md](handdrawn-style.md)）。
- **粒子**仅用于蒸汽/碎汗的消散态，且必须是 (t, state) 纯函数
  （同生长/变身特效纪律），否则 seek 校验翻车。
- **缓存 key**：本集为 `JSON.stringify([emotion,blink,lip,acting,gaze])`，
  新增 symbols 数组同进 key，key 变才重建 canvas。

## 触发纪律

- 符号必须由情绪事件驱动（呼应 performance 的 emotion 通道 /
  acting.fear/focus 阈值），触发条件写进表演谱；任何符号不常驻
  （脸红也不跨情绪段）。
- 同屏同角色 ≤2 种符号；符号与夸张表情同时出现时符号减半
  （大笑脸 + 汗滴就够，不再加爆筋）。
- 退场要准时：符号拖到下一个情绪段等于演技穿帮。

## 夸张表情拓扑

- **canvas 脸工艺**：换绘制分支，不拉伸几何。嘴放大——jaw 分支的半宽
  w 从 ±27–30 放到 ±110（半脸宽），bottom 下拉到 my+60，黑口腔、齿条、
  舌椭圆按新 w 重算。掉下巴——jaw>1 时下颌轮廓线断开，口腔黑色延伸出
  原下巴轮廓 20px，下缘加 3 条速度线。
- **3D mesh 眼工艺**：预建模 2–3 个替换眼形（豆豆眼圆片、∩ 弧管、
  全白眼片）存 `userData.altEyes`，切换 `visible`、原眼 `visible=false`；
  不要缩放原眼冒充（纵向压扁读成眯眼，见 SKILL.md 眨眼踩坑）。
- **上限纪律**：嘴不超过半脸宽，下巴下拉不超过头高 15%；
  超限读成崩坏而非夸张。

# 人物审美判断：先解释画面，再调整参数

用户要求 skill 积累审美判断，而不只是保存实现步骤。审美不是“增加细节”的
通用指令：要能看出目标角色为什么成立，当前画面失去了什么关系，以及修正何时
已经过量。本页以本片已确认的清秀少年、少女画风为例，不把一种脸型当所有角色的标准。

## 先认清目标和证据

- **美术目标**：用户确认的原始文生图，而不是程序更容易实现的简化稿。
- **实现结果**：模型正面、侧面、俯仰与连续表演。模型自身的九视图彼此相似，
  只说明是同一个模型，不证明它像独立画稿。
- **反馈状态**：区分用户认可、只认可方向、仍在试验。漂亮生产图也不能自动
  提升为模型获认可。保留失败和修正对照，说明差异，不只贴“新版更好”的标签。

## 看清关系，避免单个部位越改越重

| 判断部位 | 本片目标的视觉关系 | 常见失误 | 调整时还要一起看 |
|---|---|---|---|
| 眼形 | 靠鼻梁的一端圆而饱满，外角收尖；上睑有主次，下睑轻 | 两端都尖、统一粗线、只放大眼睛 | 两眼间距、眉眼距、刘海遮挡与脸宽 |
| 眼神 | 虹膜被上睑约束，高光有主次，目光有明确对象 | 瞳孔悬浮、白眼过多、两眼光源相反 | 偏视时眼白分配、倾听和说话的区别 |
| 侧脸 | 额头轻凸，鼻根略收，小鼻尖、嘴唇和下巴形成克制起伏 | 额头后缩、圆壳无鼻无下巴；或改成大鼻、深唇沟、前顶下巴 | 正脸下半脸长度、抬头后下颌和脖子的关系 |
| 下巴 | 清楚但不抢眼，通常略收在嘴唇后方，轮廓接回下颌 | 把尖下巴等同好看、兜下巴、回缩成脖子延长线 | 鼻唇前后位置和整体年龄感；不能只检查轮廓是否存在 |
| 鼻口 | 小而有选择的笔画，留白比厚重体积更重要 | 常驻怪笑、过大的白鼻尖、强鼻唇阴影 | 眉眼情绪、脸长与嘴角张力 |
| 头发 | 大束定流向，小束补节奏，发尖和留白有变化 | 等宽塑料条、整齐排梳、满头同亮度细线、球帽加随机碎发 | 颅顶体积、额头露出、耳后收边和左右剪影 |
| 衣料 | 清楚本色与少量有设计的阴影，主褶说明结构 | 灰白褪色、密集泥塑沟、领口碎色斑 | 肤色/背景关系、领口与脖子的连接 |
| 动态 | 转头、眨眼、说话后仍是同一个有神态的人 | 静帧漂亮而运动僵硬、脸图拉伸或贴片暴露 | 实际镜头大小、对白情绪与身体动作 |

## 每轮怎样学习

1. 先写一句具体观察，例如“内眼角也收成尖点，所以眼白像叶片”，不要只写
   “不够精致”。从目标图指出对应结构，再定位当前画面的差异。
2. 选最影响神态或辨识度的一至两项，保留同机位旧图。调整后既看改动区域，
   也看整张脸，避免鼻子修出来了却破坏少年感。
3. 检查不足与过量两头：补下巴后还要检查是否前顶；加发束后还要检查是否排梳；
   丰富虹膜后还要检查眼神是否散。不能用“缺陷的反面”自动定义好看。
4. 对照至少包含原文生图和模型，按需要加入实际生产纹理；只比较模型两代会
   逐渐丢失最初目标。技术全绿、细节变多或文件更大都不是审美证据。
5. 将有效判断、失败原因和可见边界写回来，参数留在实现文件。角色年龄、气质
   或画风改变时重新判断，不照搬本例的脸宽、眼径与下巴前伸量。

### 直接绘画试验带来的审美判断

正面提升来自保留原画中有轻重变化的睫线、虹膜的层次，以及不等宽、不等亮的
发束。这比继续添加统一的程序细线有效。但一转头，发层像薄壳、后脑像头盔，
仍会破坏同一张漂亮脸。**细节的精美程度和体积的可信程度要同时成立。**

本次可见对照在
`dula-story/episodes/bio_armor_academy_s1e4/storyboard/hybrid_character/direct_paint_v1/`：
`comparison.jpg` 对照原画、生产图和模型；`aoi_views.jpg` 暴露侧后面的边界。
判断应连看两张，不能只从正面裁切中学习。

- 头发的后脑体积要支撑脸，而非抢占脸的体量；正面发丝漂亮不能抵消侧面厚壳。
- 耳朵是连接脸与后脑的结构点。拉长的耳纹会立刻制造变形感，即使主五官很精致。
- 眼睑开合后，原有肤色与笔触应延续；用一块纯肤色覆盖眼睛会留下补丁感。
- 生成的正面生产图也会改变母图的脸型、年龄和发型比例。相似度须分开看
  “母图到生产图”和“生产图到模型”，不能把两段漂移混成贴图技术问题。
- 一次修正最多证明对应缺陷有所改善。侧面仍有薄壳、头顶接缝时，继续标作试验，
  不因正面比旧版漂亮而改写为全角度人物样板。

实施方法见 [生成绘画直接用于角色](generated-character-paint.md)，历史造型问题见
[曲面角色与绘制外观](craft3d-drawn-characters.md)。

## 用户后续纠正：圆润的关系和干净的表面

用户指出直接绘画 V1 的前后发毛糙、内眼角仍不圆、下巴出现后下颌后方过窄、
脸颊不饱满，另补充衣服串色。这说明“轮廓存在”和“贴图精细”离好看仍有距离。

- **下巴要接回整张脸。** 观察颧颊、下颌侧缘、下巴底部与颈的连续弧线。
  单独推下巴会形成尖端加细颈的楔形；需要补的是下半脸宽度、后侧下颌的体积和
  圆顺的收口，不是继续向前顶。同步核对三分之四，正面加宽不应变成侧面的平板。
- **圆内角在动态里也要成立。** 原画静帧较圆，而偏视使用另一条尖角遮罩，仍会
  读成尖眼。内端给足弧长与高度，外端保留收尖；下睑不要切平虹膜，也不要靠
  整体放大眼白制造“圆润”。检查倾听、偏视和半眨，不只看无表情正面。
- **毛糙要分清来源。** 少量碎发是设计；侧面成排锯齿、硬直边墙、后发纹理横拉
  是实现缺陷。发丝多不等于精致，平滑也不等于一大块塑料：大束体积连贯，细线
  服从束的方向，发梢有少量主次变化。加厚每一条 alpha 碎边会放大毛糙。
- **干净的衣色必须有可信边界。** 袖子上的肤色斑、领口上的红点、裙侧被当成
  手臂染肤色，都不是赛璐璐阴影。袖口、领片、领结和裙边应能读出完整衣物，
  先修语义分区，再判断色彩是否鲜明。局部上衣变好后仍检查全身，避免误伤裙装。

### 明确认可后，要学会保留

用户看到 `direct_paint_v1/render_r2/aoi_neutral.png` 后说“这张就很不错了”，
随后认可同目录 talk、firm 图。这次认可指向模型的实际正面效果，不只认可生成图。
保留顺滑的大束刘海和侧马尾、有轻重的眼线、层次清楚的虹膜与柔和但收束的下半脸。
外侧细碎发有节奏地收尾，不把所有细丝抹成圆滑实心块。

补侧后体积时，闭合发束曾把正面马尾撑厚；补脸颊时过宽的下颌又改变了人物气质。
两者都应对照认可图收回。**用户指出结构不足，不等于要求最大化该结构；用户指定
漂亮的一版后，保留它本身就是修订目标。** 用认可图与新图同机位并排检查，记录
认可的版本和角度；不能把后续自动产物一并标为已认可。V2 的
`front_target_comparison.jpg` 专门保留这项对照。

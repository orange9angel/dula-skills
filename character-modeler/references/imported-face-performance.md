# 导入角色的面部表演迭代

“支持眨眼和嘴动”只是控制通道存在。用户认为眼神呆板、人偶感强时，先保留现有视频
作为对照，分别判断造型/绑定、控制能力和表演时序，避免反复调整同一个无效参数。

## 先检查表演意图

- **视线**：每个节拍有可解释的对象，例如同伴、手臂、道具。虹膜方向要与头部、目标
  所在空间一致；凝视、转移和短暂停留服务注意力，不用持续随机眼动替代表演。
- **眼头关系**：按意图设计眼睛先看、头部随后或身体带头的顺序。允许眼睑随视线变化，
  但别把整个眼睛连同眼白、眼线一起平移；转面要遵守真实遮挡。
- **情绪**：眉形、眼睑、嘴角、下颌与台词语气共同表达同一种情绪。烤在纹理里的微笑
  可能盖过担心或制止的表情；必要时修中性脸或局部形变，单纯放大开口不会解决它。
- **听者**：没有台词仍需注意力和反应；选择少量剧情明确的反应点，避免两人一直固定
  盯着同一处，也避免两人用同一节奏同时摆动。
- **说话与静默**：口型继续由最终对白音轨及对齐结果驱动；情绪嘴角与发音开口分别控制。
  静默时保留情绪、关闭发音开口，检查句尾闭口、唇线/牙齿闪烁和转头时的嘴形。

## 再判断当前结构是否足够

纹理变形和少量局部 morph 可先覆盖有限镜头。若眼睑边界、侧脸或嘴角在所需幅度下
反复破碎，应修局部几何/权重或补独立控制，而不是继续堆摆动。新增眼球、眼睑、口腔
或更完整形变都属于后续制作工作，不能只写规范就宣称能力已接入。

S1E4 的实证：初版已有眨眼/嘴动，仍被用户否决为无神；用眼白擦掉旧虹膜再贴新虹膜
出现重影，改为固定眼睑边界的连续局部纹理形变后减少此类伪影。当前方案没有独立
眼球和完整口腔，八个保守 morph 不等于完整面部表演模型。新版已出片但审美尚未获认可。

## 用有限试片做判断

### 控制器到像素的闭环（2026-10-17）

S1E4 出现了“脚本有微笑，人物仍无神”：头部 `apply` 丢弃 `browAsym`，
男主纹理缓存只保留眨眼/视线/开口，女主微笑只在张嘴露齿时生效。先查完整路径：
导演通道 → 状态白名单与限幅 → 缓存键 → 实际绘制。闭口微笑与发音开口分别验收，
不能用静默张嘴制造笑容。新增通道默认为零，并用同机位中性脸逐像素对照确认身份未漂移。

笑眼不等于上眼睑半闭：少年角色容易因此更困。可先试下眼睑轻抬，并保留原有睫毛、
虹膜和高光。眉毛和嘴角只清理各自的局部原画区域，再变形原有线条；检查正面、斜面、
侧面是否出现双线或擦除块。角色测试图之后，还要在成片尺寸检查笑点与听者反应。

视线规则也需按剧情复核：持续的“持有道具就看道具”会盖住最后的恋爱对视。
用故事时间驱动的目标权重衔接看手、看罐子、看对方，保持 seek 可重复。

选择含说话、听者反应、视线转移和适量转头的短片；同音轨、机位、尺寸对比。先验收
改变的层级，再扩大范围。检查正常播放尺寸及必要近景；静帧、控制器数目和数值通过
都不替代连续表演判断。次级头发运动最后跟随已稳定的头部表演，发根与肩颈净空另查。

`secondary-hair.js`；校准参数见 `dula-assets/characters/bioarmor/tripo-look.js`。

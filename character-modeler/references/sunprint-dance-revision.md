# 二维画风的三维舞蹈：路线纠正

2026-10-17 咖啡厅音乐剧。用户纠正“2D to 3D 模仿文生图的跳舞”，此前整张原画
分层/网格形变虽能保留画工，却不是所要求的三维路线。不要因为二维原画漂亮就
自行改成平面动画；先确认运动要求意味着真实转体、肘膝、前后遮挡与身体体积。

本轮改为已有蒙皮身体 + 原画曲面头脸/发层 + 衣物表面绘画投影。复用代码在
`dula-assets/characters/sunprint/{CafeKid,RiggedCafeKid}.js`，
具体来源与候选证据在内容仓咖啡厅集的 `craft3d/NOTES.md`。

- **路线成立和美术成立分开。** 几何体能转、蒙皮能动，只证明机制。先前简化
  曲面白身体接精细生成头像像白色模型，不能为“真三维”降低原画目标。
- **复用身体不是复用衣服身份。** 原身体的背心、领结、裙长不能靠改白/改蓝自动
  变成目标白衬衫。纹理投影可保留衣褶；突出轮廓仍需局部几何修型。该例胸前压平、
  下摆收回有局部收益，但尚未严格还原原画，不是通用无损换装能力。
- **头身落位要在全身中判断。** 头部过小和高挂会形成长颈；延长颈管只能填空，
  不能解决比例。把头部尺度/下移与颈根参数分开，查看完整人和领口连接后再接动作。
- **同一动作的屏幕左右不等于骨架左右。** 复用的 left 骨可能位于 +X，而程序
  left 目标按画面 -X 命名。明确映射并检查腕、鞋；不因骨名匹配就认为动作正确。
- **按真实身体标定脚底。** 原程序踝高不能直接给导入模型。中性脚踝到鞋底的偏移
  来自模型；在最终骨骼矩阵后采样蒙皮鞋底，再报告支撑位移和高度。仅返回作者
  指定的目标点会制造“零滑动”假绿。本例每脚 48 个底部顶点仍只是有限采样。
- **正面绘画不是完整侧后方。** 曲面头发与帽壳能提供有限深度，但单张前发无法
  保证侧发/后脑体积。约 40° 转体试片不能扩大声称为任意 360° 发型成立。

该次修订保留原音轨与日式咖啡厅；聊天仍用原画局部表情、歌舞段改三维，须明确
描述混合范围。整集出片不意味着用户已认可画味，不把技术验收数量当审美结论。

## 用户认可后的转身细化

随后用户认可 V2 效果，要求继续细化、转身及轻快卡点。认可范围是已交付的正面及
浅转唱跳，不自动包含未展示的侧后方。新增能力先保留同机位正面基线。

- 完整转面立即暴露长发背面缺失和短发后脑横纹。后发生产绘画须真正进入有厚度
  的后脑/长发曲面；原前发 alpha 不能直接充当后发的轮廓或体积。
- 后发拓宽到耳后并不能删掉冠顶。隐藏旧 cap 后男主露头皮；保留连续冠顶并单独
  标定顶区 UV，不能用颜色混合掩盖缺面。宽幅 azimuth 图表也可能把短发拉成横条。
- 女主侧发专用绘画可修饰固定三维曲面的颜色，原前后绘画保留；这是视角加权
  投影，不能称为完整多视角几何重建。检查中间角度，不只看正面和背面端点。
- 鬓发在侧面遮满五官时，先查前发纵深。向后收时要同时约束在真实头曲面之外；
  单纯调低 templeDepth 会把发层埋进头，露出矩形皮肤。该角色用实际头曲面加
  3mm 净空，保持前视投影并让鼻口侧轮廓露出；数值不能直接移用到不同头型。
- 全身转面也会揭露服装投影污染：本例男主侧裤面采到原立绘手部肤色。色彩语义
  和覆盖区域必须共同限制，不能认为正面采样正确就已拥有侧面衣料。

角色实现仍在 `characters/sunprint/`；新后发组件 `CafeRearHair.js`。原画/保留基线/
候选的局部对照、完整转面和已编码试片见咖啡厅集 `craft3d/REFINEMENT_V3.md`。

## 面具感与全片角色统一

V3 随后被指出脸像面具，且用户要求聊天也改三维。先前对效果的认可不能覆盖这次
明确否定的面部观感；三维唱跳成立也不能自动允许聊天换回平面原画。

- 实查角色实例与每个场景分支。本例原聊天用了整张桌边原画，需替换为同一角色
  的坐姿、倾听、原对白口型、起身及收尾，不仅把开场截图换成三维静帧。
- 曲面上贴完整脸图仍会像面具：来源肤色、原画下颌边、没有光照变化的正脸与
  身体材质叠加。V4 保留眉眼鼻口绘画，退出大块底色与旧下颌线，让实际头面承担
  轮廓与明暗；耳、头、颈共享肤色响应，有限下颌位移与口型同驱动。
- 基础结构先查有限数值。本例漏传 earX 导致耳朵的世界矩阵非有限；漂亮正面和
  视频可导出都不能证明头颈完整。新造型检查可见性、实际矩阵和头面位置/法线。
- 硬色阶叠鼻部凸起会形成灰色横块。减小鼻深与放宽明暗过渡后重看整脸，不靠
  加重所有阴影证明三维。侧发的旧折叠、服装的旧细节与本轮面部修正分别报告。
- 复用导入身体的坐姿不等于布料可用。本例旧裙摆随腿骨折片，改成连续膝上裙面，
  删除被覆盖的原裙区；腰部对齐要包含身体的实际缩放，不能沿用程序身体的腰高。
  上臂覆盖不要用宽泛裸肤阈值：一次 forearm 修色误把短袖变成无袖，收紧到肘以下。
- 握勺/笔时读实际指根握点，并把指关节弯向实际掌面。仅把道具放在腕目标旁会
  漂浮；敲杯另查三维杯沿半径与高度，不能只验证杯中心的相同 y。

实现：`characters/sunprint/CafeFaceIntegration.js` 及既有 CafeKid/RiggedCafeKid。
证据与限制见咖啡厅集 `craft3d/UNIFIED_V4.md`，新增修订仍须用户复看。

### 裙壳替换后的复看纠正

用户随后指出裙子仍穿插且像贴上去，并明确所有制作手段均可、只看最终融合效果。
不能把自绘、贴图或网格复用当成质量保证，也不要再把工艺选择交给用户决定。
本集 V2/V3 已含曲面投影，解释版本差异须查源码，不顺着猜测声称 V4 才开始贴图。

- 只把新裙壳随 bob/roll 移动，腰线和真实蒙皮髋膝仍会脱节。先复查实际坐下、
  起身与转身；本例改按已求解髋膝生成连续褶裙，腰带贴合衬衫，下摆绕腿部有限
  胶囊调整。格纹跟随周长/纵向坐标，阴影来自立体褶面，而非用直格纹代替褶形。
- 删除旧裙的 rest-y 区间也可能删掉与衣物融合的腿面。全片鞋底通过无法发现
  裙下悬空的断腿；检查衣摆到膝的连续轮廓，恢复同骨架驱动的腿面，不能单纯把
  裙子拉长掩盖缺失。新腿面上缘过高也会穿出裙面，须连同服装包络一起检查。
- 坐姿裙后摆全部按站姿下垂会在双腿之间形成不合理长尾；前、侧、后区域分别
  随膝上铺展和坐面收起。胶囊净空只证明有限代理约束，不代表全衣物/桌椅零穿模。

当前可复用裙面是 `dula-assets/characters/sunprint/CafeSkirt.js`，由
`RiggedCafeKid.setPose()` 在身体 IK 求解后更新；入口与适用范围见该目录的 README。
单集坐姿、起身和舞蹈时序仍留在内容仓，不复制进共享角色或 skill。

本次 V4 交付记录保留了首次 seek 的一处哈希异常，以及之后独立像素复查和完整
48 点反向复查一致的证据。不能删掉初次失败，也不能由复查一致推断未经证实的根因。
裙面 48 个时刻对腿部胶囊留出净空，只支持该代理与这些采样；正常速度视听尚未完成，
新修订仍待用户复看。来源和验证记录指向内容仓 `config/unified_delivery_qc_v4.json`
与 `craft3d/UNIFIED_V4.md`，不在 skill 复制一套会漂移的单集数值阈值。

## 后脑过大与颜值退步的纠正

用户随后明确：原文生图头部大小合适，新增后脑太大；两层头发、耳部重复感和腰缝
仍不融合。首轮 V5 改成独立新后发包络、重排前发纵深、修改耳图，虽然有限数值检查
通过，却被用户评价“两个人的颜值都急剧下降”。这是被否决的实验，不是成熟工艺。

- 只保持绘画 XY 不足以保护身份。头部截面参数 `backZ` 同时参与前半球的中心和深度，
  改它会改脸侧曲率与绘画投影。新发壳也会盖住原画的发丝，改变发型和神态。
  必须用原画、修改前、候选的正面近景实际比对，不能只看缩小九宫格。
- 前后发映射首先统一空间与遮挡。当前回退方案沿用原有绘画、UV、前发与耳朵，
  让头皮、冠顶、前发背侧、后发通过同一深度映射一起收回；下方颈侧发束另按高度回绕。
  此法保留前视 XY，但仍是多个曲面和有限拟合，不是完整三维重建或自动无缝融合。
- 下方发束全部后退会埋进脸颊，使鬓角变成齐切块；只移动最末端又会留下护脸状折片。
  收后脑、鬓角轮廓、耳朵遮挡和侧面长发分别检查，不能以解决其中一项宣布整体完成。
  当前候选仍有侧发接缝、强侧面拉伸，须继续按实际画面评估。
- 多个绘画 hook 重复声明同名 uniform 曾造成 shader 编译失败，后发消失；
  仅监听 `pageerror` 没捕获 WebGL console error，错误视频仍能编码。渲染器必须捕获
  console error 并在首个失败帧终止，不能把导出成功当材质有效。
- 用户否定新外观后立即停止该整片任务，保留失败版本和原因，再用头像与代表片段验证。
  旧版仅作对照，不自动升级成用户批准的最终效果。
- 正常睁眼头像不能发现眨眼污染。实际歌舞 26.8 秒曾出现眼下黑色竖条：清除原眼图时，
  按整行采样的上方底色混进眉毛和刘海，再被插值拉到眼下。该角色改用明确的干净皮肤
  采样点，不改动已选眼睛图形；复查闭合、半闭、睁开和实际动作时间窗。新贴图需重新
  标定采样点，不能复制这两个角色的坐标。不得以静态睁眼恢复替代表情质量。

实现：`characters/sunprint/CafeHairIntegration.js`；候选与保留证据见咖啡厅集
`craft3d/INTEGRATION_V5.md`。这轮无新增图片或视频生成，也没有更换原声音轨。

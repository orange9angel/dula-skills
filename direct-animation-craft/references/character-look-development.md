# 人物造型精修与动画样板

用于“人物还粗糙”“与动画片有差距”“像模型或玩偶”“脸、发型、表情不自然”。
总入口为 `direct-animation-craft`；几何原型可用 `character-modeler`，色块与线条
用 `cel-look`，只有确实要生成网格时才转 `build-image-to-3d`。

## 从人物设计取舍开始

先查看最终视频、当前角色代码和已认可参考。写清本轮保留什么识别特征、改变什么
比例关系，以及选择的动画画风。用户没有新参考时沿用本片目标，不默认换角色年龄、
服装或画风。技术建议使用自己的描述，不把第三方作品名写入文件或生成提示词。

角色应有能跨镜头维持的设计关系，例如瘦削少年的小下颌与较开放眼型，力量型少年的
较宽下颌、较窄眼型和短发轮廓；这是设计示例，不是所有角色的统一模板。

按画面识别度检查：

| 层级 | 判断对象 | 常见误判 |
|---|---|---|
| 大形 | 头身比、肩宽、头颈、发型外轮廓、站姿 | 以贴图分辨率或网格细分数量代替设计 |
| 脸 | 额头/眉眼/鼻口/下巴比例，正面与侧面关系 | 正面图可爱就宣称可转面 |
| 发型 | 发壳体积、主要发束、露耳与后颈关系 | 圆壳上加随机细线，或把悬浮发片当作层次 |
| 服装 | 肩颈连接、领口、厚薄、衣摆与角色性格 | 加缝线和纽扣，却不修穿入下巴的领尖 |
| 图形 | 眉眼线条、嘴型、阴影形状和色板 | 反复加噪声、渐变和高光，导致画面更杂 |
| 表演 | 视线、眼睑、眉形、嘴角与身体意图 | 一个“生气”标签或随机摆动代替表演 |

先选最影响观感的一至两层做可比较的样板；诊断发现结构限制时处理结构，不能把
每一轮都限定为表面参数微调。已有连续网格与手部绑定能复用就复用。

在内容仓库的角色设定或本集制作记录中保留一张简短造型卡，沿用已有字段即可：

- 身份与识别点：年龄感、体型、主要发束、服装轮廓，以及本轮必须保持的特征。
- 比例与画面规则：头身比、肩腰胯关系、眉眼鼻口位置、色板与阴影/线宽层级。
- 正面/四分之三面/侧面样板，以及剧情真正需要的中性、紧张、发力或笑的表情。
- 实现入口与边界：模型/贴图路径、表情与口型接口、适用镜头及尚未解决的问题。

同一角色的后续镜头以这份样板为依据；若输出文生图，再交由
`build-continuous-story-images` 做身份与服装锁定，不能只复用一句形容词提示。

## 头、脸、发型的实际接入

1. **从镜头尺寸定细节。** 正面、四分之三面、侧面既看头部近景，也看最终成片
   尺寸；发丝、睫毛的数量不应成为主角识别度的来源。
2. **联合设计下颌、脖子和领口。** 下巴需要前后深度，脖子上端进入颅底，领根落
   在肩颈处。头相对身体低头/抬头时复查接触，必要时调整领尖，不只把头整体抬高。
3. **发束附着于统一颅顶。** 程序曲面可共用发壳的坐标参数，并让发束根部埋入
   主体；平面片的起点位置正确不证明中段没有离壳。检查侧面是否出现空隙和竖片。
   短发与长刘海使用不同轮廓，少量可控的不对称应服务角色设计。
4. **五官与说话口型属于同一面部系统。** 可以使用曲面纹理、局部网格或 morph，
   但嘴不能悬浮在脸前，远侧五官不能穿透头部。口型跟随最终对白；眉眼、眼神和
   嘴角情绪可独立控制。曲面纹理适合当前小幅表演，极端转面或近景变形需要更强结构。
5. **美术渲染与表演控制解耦。** 对白与打斗共同调用一个面部绘制器，传入 fear、
   focus、gaze、blink、lip 等实际实现的控制值。旧打斗分支不能重新盖回一张旧脸。
   同一时间点从默认路径和特写路径到达时应得到相同结果。
6. **闭嘴有情绪语义。** 中性、紧张、笑和说话开口分别检查，不把所有闭嘴画成微笑，
   不让每次露齿都读成笑脸。眨眼遮挡原有虹膜，闭眼时不残留压扁的瞳孔。

这些通道是实现建议，不是已经存在的通用引擎 API。读当前 viewer/角色接口后接入，
并保留既有音频、姿态、装备状态、道具挂点与已认可的表演。

## 用可复核的样板决定是否推广

保留一份当前基线，至少覆盖该角色实际使用的正、侧面和最难表情/姿势。
比较图复用基线的**实际世界相机位置、焦点与 FOV**；修改头高后重新追头的截图
只能称为归一化构图，不能称为同机位。截屏记录源版本、条目/时间点和生效运行模式。
试片和整片各用自己的输出及检查目录，避免一次局部探片覆盖整片构建记录；
源文件记录覆盖角色、表演、场景和实际渲染入口。

按本片风险选择验证：

- 原剧情中带口型的短片段：看说话、停顿、转头和切镜，而不仅是静态头像。
- 头相对身体的左右转、低头/抬头、半眨眼/全闭眼检查：看侧脸、耳朵、发壳、领口，
  整个人物转台不能代替头颈活动。
- 原先已认可的动作段：确认换脸、发型或构建入口没有丢失表演和装备状态。
- 顺序播放与直接 seek：检查脸图状态、眨眼和表演覆盖的确定性；数值通过后仍看实际图像。
- 出整片时检查帧数、最终 MP4 抽帧和原音轨；整片渲染成功不代表所有造型/动作达标。

证据包括前后对比图、正常速度对比片、最终片段和简短的已改/未改范围。
用户已授权改进人物时，按上述闭环推进，普通修正不另设逐轮批准。

## 2026-10-10 本集样板教训

`bio_armor_academy_s1e2/character_look.js` 是本集双角色的曲面脸候选实现：
鼻部轮廓由网格提供，嘴和眉眼在同一曲面，发束沿发壳参数附着；
`fight_trial_face.js` 对新版脸只提供表演通道，保留旧版路径供对照。
复核工具为 `tools/review_character_look.mjs` 与 `tools/compare_character_look.py`。

- 独立圆片嘴和上唇环在斜侧面容易漂浮，正面露齿时又可能读成“胡须”。本轮统一到
  脸部曲面，保留同一对白视素源。
- 鼻梁增加实际体积后，法线膨胀描边壳可能在凹陷处露出一条错误的内轮廓。
  不要用“描边更细”反复掩盖；按目标选择去掉该壳或实现真正的外轮廓遮罩。
- 圆发壳上加散乱短管不等于短发。短发先改顶部与发际线的大形，碎发只是可选细节。
- 定姿对照通过后，低头检查仍发现领尖侵入下巴，必须联合修领口。
- 外观版本写入构建记录并保存关键源文件哈希；已认可的正式表演入口作为默认配置，
  旧动作明确 opt-out，避免后续外观精修重新使用旧动作。

这一实现与样板说明制作与验证方法，尚不能作为“商业动画质量已达标”的证明。

### 同日用户复看后的修正

用户指出脸部色块奇怪、其他细节仍与目标有差距。前一版的“干净色块”不能视为
已认可结论；先回到 `cel-look` 核对肤色、实际材质路径和 UV 接缝。R19 在统一肤色
之外修了鼻尖突出过大、下颌后缩、发顶折面，以及肩部球形盖和衣料分档光照。

- 调低发壳的顶部，可能让**前额中段**穿出皮肤；壳顶比头顶高不代表壳面处处包住头。
  复查正面、斜侧、侧面与俯仰。该样板保留原包覆范围，只平滑短发冠部的转折。
- 移除肩部球盖后，袖根与上臂根要一起处理：袖根接入胸廓，隐藏原本就被袖子
  覆盖的上臂表面，再检查抬臂。不能只删一个球，留下裸露皮肤尖片或袖根洞口。
- 成片对白镜头较远时，额外用相同世界机位渲染带原对白的近景对照。近景用于
  检查肤色与五官，不替代整片构图或实际动作验收。

本轮同机位证据在 `bio_armor_academy_s1e2/storyboard/skin_refine_20261010/`；
`character_finish.js` 仅是该集的肤色/衣料/袖根适配，尚未推广为共享角色规范。

### 后发过短与假发感：先修后脑和后颈的关系

用户认可 R19 肤色后，指出两人后发过短、像戴上去的。正面和侧面检查不足以发现
这个问题：原发壳在下后脑提前终止，露出一圈头皮，后发与耳后、后颈脱节。

- **增加侧后与正后样板。** 至少保留正面、四分之三、侧面、侧后、正后五个方向。
  用相同世界相机对照；环绕视频能检查另一侧，但必须另做头相对身体的俯仰检查，
  防止发尾穿入脖子或低头时露出断层。定姿环绕只证明外形，不能代表发束动态。
- **长度和体积一起改。** 直接延长椭球发壳会形成膨大的圆帽或齐发团。后脑截面
  应参考实际头部轮廓，沿耳后向后颈逐渐收紧，发尾与颈部仍留出合理距离。
  发壳根部、主发束、后颈轮廓共用曲面参数，不能各自拼接一圈独立片。
- **按角色区分发束尺度。** 较长发型用少量宽发束交叠、错开起点和长度；短发用
  短而贴近后颈的收边。不能给短发角色套上从头顶直垂到底的长发片。
- **避免规则竖条和贴片。** 等长、等宽、同起点的高反差发片会读成一排椭圆色条。
  根部埋入主体，颜色从发壳逐渐过渡，边缘减少反差，再按生长方向组织发束。
  随机加细线不能解决体积与附着问题。
- **检查颈部余量。** 后发跟随头旋转，脖子留在身体上；仅静态贴合仍可能在抬头时
  露出头皮缺口。检查发尾前后深度及颈部截面，不以“后发越薄越好”代替接触复核。

本次 R20 证据在 `bio_armor_academy_s1e2/storyboard/hair_r20/`，保存 R19 原始源码、
同机位五视图与俯仰样板；`tools/review_character_look.mjs --orbit-video` 输出定姿
环绕，`tools/compare_character_look.py --portraits` 可选择侧后图做对照。R19 已认可
的肤色保持不变；此轮解决后发覆盖和轮廓衔接，发束次级运动仍未实现。

# 动画原则可执行配方

动作"能放但不像动画片"（发力没重量、急停即静止、全身刚性、高速段发飘）时读本文件。
每条原则给：何时用、数值配方、实现路径、翻车警示。帧数按 30fps 基准，换秒除以 30。
一拍二的严格定义与关键姿势组织见 [SKILL.md](../SKILL.md)；coil 蓄力、打击特效
（冲击环/白闪/拟声词大字）已在格斗参考与踩坑记录中，这里只引用不重复。

参考结构（以 bio_armor_academy_s1e2 为样板）：`performance.js` 按 phase switch 在
条目相对进度 u 上给出 rootX/rootZ/yaw/bob 与手部目标位，`ease()` smoothstep 混合，
条目边界 0.3s 缘插值；`buildPose` 用 twoBone 解四肢、hipY 托住双脚，肢体为刚性
LimbSurface 类分件；`render.mjs` 30fps 逐帧全采样。所有附加运动必须是 (t,state)
纯函数——顺序渲染与 seek 一致是本集铁律，不能引入"上一帧"状态。

## 预备（发力前的反向蓄势）

何时用：观众需要"看见即将发生"的发力动作——挥拳、起跳、冲刺、推拒；对白级抬手、
转头只要微动预备。

配方：
- 大动作：预备 0.15-0.30s，反向位移为发力行程的 15-25%（拳行程 0.5m 则先收
  0.08-0.12m，冲刺前躯干后仰约 0.1 rad）；预备与发力时间比约 2:1 到 3:1。
- 小动作：2-4 帧反向微动即可（转头前反向 0.02-0.04 rad）。

实现：把谱面里的单个 ease 拆成两段——先反向 ease-out 蓄势，再正向急出发力：

```js
const wind=0.06, strike=0.14; // 条目内 u 区间：先收后打
if(u<wind)s.right=blend(GUARD,COIL,1-(1-u/wind)**2);   // 反向蓄势，缓出
else s.right=blend(COIL,HIT,ease((u-wind)/strike));    // 急出发力
```

翻车警示：预备幅度超过发力行程 30% 会读成"先退一步再演一遍"；条目边界的
0.3s 缘插值会吃掉本条目开头的小预备，跨条目的预备要放进上一条目末尾。
反面案例：本集 charge1/2 冲锋段无起步预备，拳从 u=.45 直接 ease 出（遗留项，
中性记录），按本节两段拆解即可补上。

## 跟随与重叠动作（到位之后不同时停）

何时用：任何急停、到位、转向之后。主肢停了而全角色瞬间静止，就是缺它。

配方：
- 末端（手腕、头发、衣摆、绷带）在主件到位后继续运动 0.1-0.4s，阻尼衰减振荡：
  `settle(t)=A·e^(-k(t-t0))·cos(ω(t-t0))`，k≈8-12，ω≈20-30 rad/s，
  A 取主件过冲量的 0.3-0.6。
- 起动错开：视线→头→肩→重心依次晚 2-6 帧起动——"眼神、头、肩和重心可以错开
  起动"（见 [格斗表演](fight-performance.md)）在此升级为帧数配方。

实现：谱面是纯函数，把衰减振荡写成关于 `(t-t0)` 的解析式，t0 为主件到位时刻，
A 由主件到位速度估算（A≈v0·0.03-0.05）；错帧起动=各部位用不同的 u 偏移采样
同一条 ease 曲线。

翻车警示：振荡拖过 0.5s 像果冻；k<5 时衰减不完就接下个动作，与条目边界缘插值
互相打架；settle 必须是 t 的纯函数，否则 seek 与顺序渲染分叉。

## 次级运动（挂载件的弹簧跟随）

何时用：发束、外套襟、书包、围巾、挂饰等挂载件。本集现状是衣物/书包/发束全部
刚性焊死、零跟随。

配方：
- spring-damper 追踪主件：刚度 30-80、阻尼 6-14。硬材质（书包、甲片）取高刚度
  短滞后，软材质（发束、衣摆）取低刚度大摆幅。
- 跑步/落地时书包滞后 3-5 帧（0.10-0.17s）。
- 程序化发型按发束 group 加旋转弹簧，不逐顶点模拟。

实现：受 (t,state) 纯函数约束，弹簧不能逐帧积分累计（seek 会发散），两条路：

1. 解析近似（首选）：跟随件角度 = 主件在 `t-τ` 时刻的采样（τ=滞后 0.10-0.17s）
   叠加上节的 settle 过冲项——保持纯函数、seek 安全；
2. 真弹簧：从镜头起点定步长积分到 t，每帧重算，成本随 t 线性，只用于短镜头。

最小接入：衣物书包与肢体同为刚性分件时，只对挂载件自身 group 写局部旋转/位移，
挂在 buildPose 之后、setPose 之前，不重开蒙皮、不改 IK 求解结果。

翻车警示：弹簧积分用 wall-clock dt 直接破坏顺序渲染与 seek 一致；刚度 <20 且
阻尼 <4 会永远晃；挂载件摆幅的极值帧要抽查是否穿进躯干。

## 挤压拉伸（受力瞬间的几何形变）

何时用：落地、受击、发力瞬间。本集现状：落地/受击只有 bob 位移，几何零形变。

配方：
- 落地压缩：躯干 scale.y 收到 0.85-0.92，持续 2-4 帧；回弹 overshoot 到
  1.03-1.05 再归 1。体积守恒：压 y 时 xz 胀到 `1/sqrt(sy)`。
- 冲刺/发力拉伸：沿运动方向 1.05-1.15，只在高速段（速度 > 身高×1.5/秒）启用。
- 时序对齐 bob：压缩谷底 = bob 最低点，回弹峰在触底后 2-3 帧。

实现：只作用在躯干/头部 group 的局部 scale（torsoMatrix 之外另包一个 squash
group，或直接写躯干 mesh.scale），绝不改 IK 目标位和骨长——twoBone 的骨长有
数值断言约束（本集阈值 0.002 量级），缩骨架会直接违反。

翻车警示：整角色均匀缩放是橡皮人，不是挤压拉伸；压缩低于 0.8 在非 Q 版比例上
读成穿地；scale 必须由 u/t 推出，保持纯函数。

## 涂抹帧与残像（高速段的中间帧处理）

何时用：位移速度超过 角色身高×2/秒 的中间帧（本集角色约 1.6-1.8m，即 >3.4m/s：
冲锋后段、击飞段）。本集现状为零。

配方：
- 涂抹：mesh 沿速度方向非均匀拉伸 1.5-3 倍，只存留 1-2 帧；
- 残像：复制 1-2 个前一姿势的半透明副本，opacity 0.25-0.4，同样 1-2 帧即撤；
- 相机静止时效果最佳；跟拍镜头（相机与角色同速）慎用，涂抹会读成模型事故。

实现：谱面里速度可解析求（move 的 ease 导数），超阈值时在 buildPose 返回后沿
速度向量缩 group.scale，或用前一姿势的克隆做残像；残像副本的 visible 必须由 u
控制，不引入新状态。

翻车警示：30fps 下 3 帧以上的涂抹是拉丝；残像 opacity >0.5 读成分身；低速段
（<身高×1.5/秒）涂了等于变形事故。

## 一拍二的落地策略

一拍二的严格定义与 30fps 换算见 [SKILL.md](../SKILL.md)，不重复。分层落地：
- 姿势/表情 15Hz 更新：pose 采样量化到 `floor(t*15)/15`；
- 相机、根位移轨迹保持满帧率，否则镜头发涩；
- 各层时钟分离（呼应 cel-look 的曝光节奏纪律）：口型、光效、特效锚点各自声明
  采样频率，音频时间永远不量化；
- 打斗 contact 帧必须落在 pose 更新帧上——命中瞬间要有新姿势，不能落在保持帧
  里；排谱时把命中 u 对齐到 1/15s 网格；
- 本集 render.mjs 为 30fps 逐帧全采样、无一拍二，属待改造现状；从单个动作的
  pose 量化试起，不整集一次性切换。

翻车警示：pose 量化后，条目边界 0.3s 缘插值也要量化，否则出现"量化姿势+连续
插值"的混合抖动；一拍二下高速涂抹帧只剩 1 帧可见，酌情退回一拍一。

## 动作线与强剪影

何时用：每个关键姿势落谱之前。

配方：
- 先用一条 C 形或 S 形曲线概括脊柱走向，四肢挂在曲线两端；胸与髋朝向差
  >0.6 rad 时检查动作线是否折断；
- 验收：角色填纯黑的剪影下能读出动作意图；四肢不贴躯干、不互相遮挡主轴；
  拳/脚等叙事末端必须落在剪影外轮廓上；
- 每个 phase 的手写目标位先过剪影验收再写进谱面，比写完再修便宜。

翻车警示：正对镜头的直拳剪影是一坨圆——给 10-20° 侧向偏移或让相机侧 15-30°；
checkTimes 静帧抽查时加一张纯黑剪影模式，比看完整着色更快暴露姿势问题。

## Timing 配方表（30fps 基准）

| 动作 | 帧数 | 备注 |
|---|---|---|
| 快步走循环 | 16-20 | 步频约 1.6-1.9 步/秒 |
| 跑步循环 | 10-14 | 腾空期占 20-30% |
| 挥拳 | 预备 8 + 发力 3 + 缓冲 10 | 发力 3 帧内到位，不 ease 全程 |
| 转头 | 8-12 | 超过 12 帧读成"慢慢看" |
| 起跳到落地 | 按抛体公式 | 竖直 v0 与 g 决定帧数，不拍脑袋摆 u |
| 受击僵直 | 6-10 | 僵直结束再接击退位移 |
| 大动作预备 | 5-9 | 见预备节 |
| 落地缓冲回弹 | 8-12 | squash 谷底在前 2-4 帧 |

## 接入顺序

一次只加一层，按性价比排序：预备 → 挤压拉伸 → 跟随衰减 → 次级运动 →
涂抹帧 → 一拍二量化。每加一层跑一轮顺序渲染 + seek 对照 + 剪影抽查。层间
数值互相影响时（squash 改变 bob、smear 依赖速度），后加的层读前层的输出，
不各自重算。

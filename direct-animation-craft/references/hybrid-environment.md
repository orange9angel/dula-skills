# 二维三维混合环境与非匀速运动

用于已有三维角色或场景，希望获得绘制背景的自由形状、风的起伏、飞鸟、落叶及视差。先检查用户指定成片与实际动作代码，再选择实现；背景静止通常是尚未编排环境动作，不能归因于三维无法表现。

## 分配空间与绘制工作

| 元素 | 可选实现 | 需要检查 |
|---|---|---|
| 人物、地面、树干、近景道具 | 三维模型或简化代理几何 | 转面、接触、透视和真实前后遮挡 |
| 远山、云、树冠色块 | 手绘/程序绘制贴图，挂在空间中的远景面、圆柱或分层卡片 | 相机移动时的视差、接缝与侧面露馅 |
| 叶片、远处鸟群 | 二维轮廓或动作帧，沿三维轨迹运动 | 深度测试、镂空区域、尺寸随距离变化 |
| 柳条、草叶、发梢 | 三维曲线或薄片变形 | 根部固定、末端延迟、与同一阵风方向一致 |
| 水纹、光斑 | 地表上的图形或细线 | 留在水面/地面上，不能跟随屏幕漂移 |

世界中的叶片和飞鸟应参与深度测试，不能把整层始终画在人物之上。硬边平涂贴片可使用 alpha test 并写深度；半透明、柔边素材另处理混合与排序。远景朝向相机的卡片适合简洁轮廓；近距离绕拍鸟、树冠或云，需要多视图素材、体积结构或三维替身，不能把远景方案称为任意近景都成立。

## 同一阵风，不同响应

先在权威时间轴写明起风、峰值和消退，使用快速建立、较慢回落的包络，再叠加幅度较小的变化。风向在世界空间定义；角色转身时把风向变换到角色/头部局部坐标，不能让风跟着人物转。

草叶可较快响应，柳枝较慢，发梢和松散物体各有延迟与幅度。相邻物体共享风的主要起伏，用位置传播延迟和少量相位差避免整片同摆。根部固定，变形随离根部距离增加；需要回摆时明确设计衰减，不用每帧随机数代替自然运动。

漂浮物的位置应累计速度：`x(t) = x0 + integral(v(t), t0, t)`。不能用 `x = t * wind(t)`；风减弱时后者可能倒退或跳动。程序管线可预先固定步长积分，再按绝对时间插值，保证顺序播放与任意 seek 一致。随机参数从物体固定种子生成，禁止依赖调用次数。

飞鸟同时设计轨迹、速度、扑翼和滑翔。群体共享大方向，各只错开起飞时间、高度和扑翼相位；扑翼循环中安排滑翔窗，不要让所有鸟同步开合或让整片背景同频呼吸。飞行轨迹和扑翼是两条独立控制曲线。

## 最小验证

- 用同一人物、动作、相机做环境暂停/运动对照；避免只靠换背景色或镜头来制造改善。
- 看起风、峰值、衰减、叶片经过人物前后以及鸟从枝条后飞出的连续片段与抽帧。
- 检查预定机位范围，区分角色原地转台和摄影机绕场景旋转。
- 检查累计位移单调性、明显但连续的速度变化、确定性种子、顺序渲染与直接 seek。数值通过不能替代动作审美评审。
- 环境音与画面有对应的叙事事件时再按同一时间轴配音；无声工艺试片不声称音画同步已完成。

## 小雪河岸试作（2026-09-23）

用户参考 E08 `painted/output/output.mp4`。该成片为 60s / 1080p / 30fps；检查了成片抽帧与 `painted/painter.js` 的分层视差、阵风包络和飞鸟调用。本轮在小雪已有 `craft_trial/` 新增河岸场景，没有改写参考片或原正片。

`environment.story` 记录两次阵风和两批鸟的局部工艺检查时间；`environment-motion.js` 从绝对时间求值，并以 240Hz 固定步长累计漂移速度；`environment3d.js` 组合三维树干、地面、曲线柳条与二维远景、树冠、叶片、九态扑翼图形。`head3d.js` 接受世界风向，换到头部局部空间驱动发梢。

动态与静态环境各输出 12.4s / 1080p / 30fps / 372 帧；并排对照为 1920×540。两版各 16 帧直接 seek 一致，积分基准速度约 0.687–1.987 场景单位/s，峰谷比约 2.89；落叶位移另乘统一比例。鸟群前进方向与 seek 稳定性检查通过。旧室内角色 16 个关键帧哈希保持一致。看过环境、飞鸟成片解码图及额外五个摄影机方向；当前是简化河岸和远景鸟，未实现树木细节特写、鸟的完整三维解剖、流体/布料物理求解或环境音效。

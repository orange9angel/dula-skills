# 粒子角色、人偶→肉体感与粒子变身成 cel（crystal_aria，2026-10-30/31）

参考实现：`dula-story/episodes/crystal_aria`（`hybrid/aria_pilot.js` 单页，全曲 74s，分段 `?win=起,止` 渲染）。
用户目标：**不用视频大模型**，用文生图 + 程序层把动作做顺。

## 1. 程序化粒子角色（不用模型文件）
- 用户否决 GLB 当粒子源（「我们不是粒子特效，你用 glb 做什么」）：画面里只有粒子，现成模型要大改造型。改为代码定义成年比例骨架（FK：根/骨盆/胸/头 + 上臂/前臂方向向量 + 锁骨），编舞写关键帧（歌曲秒），Fritsch–Carlson 单调插值防过冲；重叠动作：头晚胸 0.06s、前臂晚上臂 0.05s。
- 纱裙对 yaw 做二阶弹簧滞后，**从全曲起点积分**，分段渲染结果一致；纱袖取过去 0–0.22s 的手臂形成拖尾。
- 「人偶感」用材质与小幅僵硬表达，**不要用定格卡点**（用户：「女性舞蹈，不是卡点街舞」）：拍点吸附只混 35%，每拍缓进缓出占 85% 拍长。

## 2. 人偶 → 肉体感（用户：「这个非常重要」）
人偶感四个来源与对策：
1. 圆柱拼接 → **平滑融合隐式曲面**（smooth-min，k≈2.2cm；肩部体块单独 3–4cm）：髋、腰、胸廓、胸、斜方肌两段（颈根斜下到肩峰）、颈、颅/面颊/下巴/鼻、三角肌顺上臂拉长包住上三分之一、变径胶囊四肢、掌指、腋前后褶。粒子撒在等值面上（牛顿投影 6 次）。
2. 刚体 → **两骨距离蒙皮**（各体块 exp(-d/13mm) 按骨累加取前两骨），静止姿与动画共用同一 FK。
3. 抬臂露空 → **逐帧在当前姿态的融合曲面上重新吸附**：静止姿采样漏掉了关节内侧的肉；每骨记当前→静止逆变换，体块在各自骨的静止坐标求值，只对跨骨粒子做 2 次投影，法线取当前梯度。
4. 平涂 → **逐粒子法线明暗**：受光暖白、背光冷紫（透光感）、轮廓光 ≤0.16、背向镜头压暗（additive 无深度时的体积近似）；皮肤/衣料分材质。
排查纪律：「看起来断开」先开无光照模式（`?flat`）分清几何还是明暗——锁骨亮棱+暗沟、肩头浅凹背光、轮廓光描内折痕都会读成接缝，不要一味加体块。关节处粒子缺失先看沿肢体的粒子直方图（采样丢弃条件「在并集内」会把融合鼓包里的点全丢）。

## 3. 粒子角色的脸与口型
- 粒子数撑不起五官（近景脸 ~200px 要上万点；几何着色五官放大后是蛋）。**发光肖像面片**：同一 SDF 从正前方射线求交得浮雕网格，贴正面身份锚肖像，着色器按像素闪烁画成光点，深度/半径/视向法线淡出（侧脸露硬边），该区头部粒子按 pw³ 压暗（线性压暗在淡出带成黑环）。
- 唱段口型：全曲 `align_sung_lyrics.py` 逐字韵母定形 + 能量定开合，着色器透镜形暗红口腔；**唱 i 不画牙**（用户：「这种嘴型不会露出上牙吧」）；平滑以 t+30ms 为中心对称（只往回看会被前字拖成大口）。
- 近景按真实比例放大背景：球半径约画高 6 倍、球边在画外（3.2 倍时手臂像伸出球外）。

## 4. 粒子变身成 cel（青蛙王子式）
- 碎球：裂纹端点崩屑 → 碎时数千玻璃粉尘（阻尼外飞、重力、落台面闪烁、轻的上飘）+ 不规则三角碎片（抖动极坐标网格，部分飞向镜头，翻转镜面闪）+ 冲击光环；去球底图用 codex 编辑、只把球区圆形羽化锁回（r×1.2，r×1.07 残留球边）。光云要实心（只外推成甜甜圈）。
- 聚拢：从目标 cel 的 alpha 采样上万目标像素，光点螺旋落位（裙摆先、头最后），cel 按同一时间表自下而上显现；所有调光/亮边用临时层 `source-atop` 只染人物像素（直接叠在外接矩形上会出现矩形背景）。
- 尾奏连续动作见 SKILL.md「姿势阶梯」：用户实看后选 **4 张中间画、曝光 5/5/3/3、头部对齐、换画前 1 帧 50%**（v2），一拍二加密（v3）与裙摆配准（v4）都被判更抖。

## 5. 声音
Seed-Audio 事件音效按画面事件点摆放（at = 事件 − 素材起音），对位检查读总线上事件点附近最响的 20ms，而不只靠 onset 检测（软起音的光爆、渐强的汇聚检测不到）；晚落的碎屑叮当会撞进下一个事件，按事件点截尾淡出。旁白跨进纯伴奏段时音乐 −6dB，语音频带人声/音乐中位 ≥ +10dB。

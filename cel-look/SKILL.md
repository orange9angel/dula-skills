# Cel Look（三维做的像二维）

目标：在造型与动作成立的基础上，统一轮廓、色块和时间节奏，达到约定的二维画面风格。
实现参考：`yuki_morning_battle`（sketch 实验及已知造型局限）、`yuki_beat_ad` V17
（口型平面化 + 猫描边）、`dula-engine/handdrawn/`（sketchify + BoilSystem）。这些是代码参考，不是默认合格的美术样板。

遇到球手、棍状四肢或弯曲轮廓不成立，先读 [动画作画监督](../direct-animation-craft/SKILL.md)，再处理本文件的画面风格。加描边、增加细分、抽帧不能补上缺失的造型与表演。

## 在造型与动作之后整理画面

1. **轮廓线**：干净动画使用稳定、可控的外轮廓，减少内部接缝线，细节线弱于主体轮廓。速写风可使用 `sketchify()` 和 `BoilSystem`；抖动与碎线不是所有画风的默认项。线色按色板选择，暖黑或纯黑都可以。无描边风格也可能符合用户目标。
2. **色块阴影**：干净赛璐璐可从底色加一档阴影起步，按样板选择色阶和阴影色相。避免塑料高光及过多明暗切面；具体数量并非所有动画的统一标准。
3. **脸部图形**：平面嘴、眼部贴片或局部修型有助于控制图形。按镜头检查侧脸、转头、遮挡和透视，不把所有五官永远 billboard 朝向相机。
4. **曝光节奏**：从关键姿势与动作节拍决定一拍一、一拍二或长停格。24fps 一拍二为 12 次姿势更新，30fps 一拍二为 15 次；在 30fps 上直接 `floor(t * 12) / 12` 会产生 2/3 帧保持交替。使用输出帧号/曝光表，不能把固定 12Hz 当通用修复。
5. **各层时钟**：摄影机通常维持输出帧率；角色姿势、根位移、脸部和口型明确各自策略，检查组合后是否滑步、漂移或失同步。口型可以使用离散曝光，但必须保留声音起止和闭嘴事件，音频时间不量化。

## 检查清单（出片前逐项过）

- [ ] 剪影、关键姿势和手脚语义先成立；形变问题已归回资产或作画层处理
- [ ] 线条符合目标风格；干净线稿没有无意的毛边、碎线或内部黑圈
- [ ] 色块、阴影与角色样板一致
- [ ] 手型切换/连续变形符合镜头需求，腕口和持物接触稳定
- [ ] 脸部图形在本镜头的转面范围内成立
- [ ] 动作的受力、缓冲、停顿合理，形变服务表演
- [ ] 实际输出帧保持符合曝光设计，口型贴合声音，足部没有因时钟分离而滑动
- [ ] 同机位静帧与连续短片都已检查；技术全绿不等于审美达标

## 翻车记录

- **细化阶段必须配视觉护栏**：机械断言（闭嘴/穿模/帧数）全绿也可能观感回退。
  用黄金帧回归：监制认可版渲染关键帧存 `storyboard/golden/baseline/`（入库），
  之后在相关改动时重渲染同批帧做像素对比，超阈值出并排 diff 图。diff 只能定位变化，不能自动判断变化的美术质量。
  参考实现：`yuki_fish_musical/tools/golden_frames.mjs`（2026-09 立。
  首次实战就证明了价值：手型集被误判"改坏"，harness 对比证明它是无辜的，
  真正的发梢毛边是上一版存量问题）。
- 为便于判断原因，按造型/动作/线条组织可比较的修正。沿用用户既有授权和明确的审美反馈，普通迭代不新增逐批批准要求。
- sketchify 的 boil 必须由渲染时间驱动（`BoilSystem.update(time)`），
  用 wall clock 会破坏离线渲染的确定性（V17 已验证同帧逐字节一致）。
- 描边宽度是局部单位，小部件要自动收缩（sketchify 已处理）；猫背面
  尾巴线条在 0.014 下略粗，特写场景降到 0.012。
- 一拍二不要全局套：BG 平移、摄影机、角色姿势、根位移和口型按曝光设计协调，检查落脚和口型时机。
- **按既有目标选描边；风格不明确且影响工艺时再问**：sketchify（顶点抖动 + boil + 碎线）是
  "手绘速写"路线；干净动画需要连贯、粗细有设计的轮廓，不必全部等宽。
  检查当前实现中的抖动、overshoot 和硬边碎线；需要稳定线条时选用相应轮廓实现，
  不假定仅把 boil 关掉就能消除全部碎边。
  参考实现：`yuki_fish_musical/bootstrap.js` 的 `cleanOutline()`。
- 锥体尖端（双马尾末端 ConeGeometry）顶点法线分散，逆向壳会在尖端炸成
  平行细线：先把中轴顶点法线统一收到轴向（smoothConeApex）再描边。
- **小雪造型复核（2026-09-21）**：球手、单段四肢和胶囊靴在描边后仍然缺少手脚结构。优先重做可读轮廓、弯曲控制和接触；不要把接缝毛边一律归为“手绘质感”。见 [案例诊断](../direct-animation-craft/references/yuki-morning-battle.md)。

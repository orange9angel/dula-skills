# Cel Look（三维做的像二维）

目标：观众第一眼认为是手绘动画片，而不是"3D 小游戏"。
参考实现：`yuki_morning_battle`（sketch 模式全片）、`yuki_beat_ad` V17
（口型平面化 + 猫描边）、`dula-engine/handdrawn/`（sketchify + BoilSystem）。

## 为什么 3D 会"露馅"（按观感影响排序）

1. **运动太顺滑**——全帧率插值是 CG 最大的气味。商业 2D 动画是"一拍二"
   （12fps 摆姿）甚至一拍三。修补最便宜效果最大：角色姿态/表情按
   `tq = Math.floor(t * 12) / 12` 量化采样，**摄影机保持全帧率**。
   注意：一拍二作用于动画系统，不作用于口型（口型要贴声学时间）和
   摄影机（否则画面卡顿）。
2. **没有线稿**——轮廓线是手绘的第一信号。用 `sketchify()`（逆向壳描边 +
   硬边细节线），配 `BoilSystem` 12fps 抖动。线色用暖黑（如 0x25222a），
   永远不要纯黑。
3. **球手**——球端手臂是廉价 CG 的代名词。见 character-modeler 的手部段落：
   至少是"压扁胶囊 + 拇指楔形"的连指手套形，动作重点镜头可用 4 指卡通手。
4. **光照太立体**——商业赛璐璐是"底色 + 1 档阴影"的两段式。把 toon 渐变
   改成 2-3 档硬切（gradientMap 的阶梯拉陡），压掉高光，阴影色向主色
   色相偏移而不是简单变暗。
5. **脸是 3D 的**——眼睛/嘴在 2D 里是画在脸上的平面图形。嘴已可用平面
   轮廓唇（beat_ad lipsync 链）；眼睛高光/瞳孔可以用面向相机的贴片。

## 检查清单（出片前逐项过）

- [ ] 角色动画姿态 12fps 量化（抽一段快速动作逐帧看：pose 应 2 帧一变）
- [ ] 所有角色有描边，线色不是纯黑，boil 在动
- [ ] 阴影是硬边色块而非渐变
- [ ] 手不是球
- [ ] 快速动作有 squash-stretch，起跳/落地有形变
- [ ] 口型不在抽帧范围内（口型帧率独立）
- [ ] 静帧截图：任一帧读起来像赛璐璐 still，不是游戏截图

## 翻车记录

- sketchify 的 boil 必须由渲染时间驱动（`BoilSystem.update(time)`），
  用 wall clock 会破坏离线渲染的确定性（V17 已验证同帧逐字节一致）。
- 描边宽度是局部单位，小部件要自动收缩（sketchify 已处理）；猫背面
  尾巴线条在 0.014 下略粗，特写场景降到 0.012。
- 一拍二不要全局套：BG 平移、摄影机、口型都要保持原帧率。

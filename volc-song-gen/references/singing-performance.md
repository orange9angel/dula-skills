# 成曲接入唱跳表演：验证边界与故障记录

生成成功只证明有音频。音乐适配、歌词口型、舞蹈动作需要分别检查。
参考实现：`dula-story/episodes/yuki_beat_ad/tools/prepare_v10.py` 与
`performance_v10.js`。本轮结果是程序角色的新试片，未获得用户播放验收。

## 歌词与嘴形

- HPSS harmonic 是谐波分量，仍含伴奏；不能称为纯人声分离。V10 使用本地
  Hybrid Demucs 分离 final master 的 vocals/drums，最终影片仍使用原混音。
- `faster-whisper.transcribe(initial_prompt=歌词, word_timestamps=True)` 是带提示
  的转写，不应冒充已知文本强制对齐。V10 使用 `find_alignment` 给定歌词 tokens
  做 cross-attention/DTW；中文逐字编码，避免把一个多字 token 的时长机械均分。
  [上游实现](https://github.com/SYSTRAN/faster-whisper/blob/master/faster_whisper/transcribe.py)。
- DTW 也可能把前字拖音、长休止并入后字。保留 raw 边界，用分离人声包络检查
  内部静音区；保留前字尾音，再把下字起始移到休止后。不要用最近鼓点校正唱词。
- 字符时间不是音素时间。拼音可提供 MBP 闭唇、FV 唇齿、A/E/I/O/U 元音的近似
  视素；辅音时长和复元音转换仍是规则估计，不能声称真人级或精确音素级 lip sync。
- 静音闭嘴必须覆盖所有表情。旧版在静音时回退到张嘴笑，导致包络已归零但角色
  仍像在唱。长元音要保持嘴形，而非每个汉字重复 open→half。
- 输入、分离轨、对齐缓存都记录音频 hash；母带重剪后必须重新分析。词概率只
  是模型 token likelihood，不是对齐精度评分。

## 舞步、道具与验收

- 剪辑在拍上不代表跳舞配合音乐。按完整乐句写动作，歌词选择动作，鼓点选择
  脚落地/手击中的时刻；切镜不能重置尚未结束的旋转或跳跃。心跳不等于跳跃指令。
- 为动作保留蓄势、到位、收势；脚步段用全景，唱词重点再推近。减少每拍换装，
  让观众有时间读清动作。
- 持麦动作需要手、麦杆、麦头与头部的空间检查。双手舞蹈可以改用耳麦；这是
  表演设计选择，不应把“移除手持麦”描述为已修好持麦 IK。
- 程序双节肢体需补关节球、脚掌反向旋转、脚底高度约束。胶囊相接只是端点
  相触，弯曲会露缝；只验证关节坐标不会发现这个视觉问题。
- 全帧检查：休止闭嘴、每字覆盖、双唇音闭合、动作连续、足底不入地、手与头部
  代理体距离；再检查最终 AAC、帧数和音画起始时间。代理体检查不是精细网格碰撞。
- 正常速度视听与用户反馈才决定观感。不能从“0ms 吸拍”“无浏览器报错”“检查帧
  通过”推导出音乐、舞蹈或口型已获审美验收；负面反馈必须覆盖早先的乐观结论。

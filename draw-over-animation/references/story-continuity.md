# 混合绘画的剧情连续性

单张图的身份一致、局部锁区、镜表覆盖和确定性渲染，都不能证明剧情成立。
镜头之间要传递“刚才发生了什么、当前还受什么约束、下一次变化由什么触发”。

## 共用状态，镜头只选择表现

动作与事件时点回到 `script.story` 正本。用共享
[`story-state.js`](../assets/story-state.js) 按绝对时间求持久状态；近景、远景、
插入镜头和嵌套试片均读取它，不能每换一张人物图就落回默认状态。

```js
const state = createStoryState({cues, tracks: {
  shield: [
    {at:0, value:'held'},
    {at:{cue:'TRAP'}, value:'wedged'},
    {at:{cue:'FREE'}, value:'held'}
  ],
  strain: [
    {at:0, value:0},
    {at:{cue:'HIT'}, value:1, duration:.1},
    {at:{cue:'RECOVER'}, value:.2, duration:3}
  ]
}}).at(t);
```

状态本身不自动修图。逐镜列出需要的可见关系，并让所有图层共同满足：

| 事件 | 前镜与本镜必须看见 | 后镜必须继承 |
|---|---|---|
| 盾卡入槽 | 盾端到达槽口，槽沿遮住插入部分 | 盾仍压槽、身体保持相应支撑、链端仍在接触处 |
| 脱开 | 解锁/断链依据，盾端确实离开槽口 | 允许重新手持；战损持续 |
| 受击后说话 | 嘴形可以变化，眉眼仍有痛感 | 逐步恢复或在明确新情绪触发时改变 |
| 转身离开 | 躯干、头与支撑脚转向路径 | 新朝向向前换脚，不能倒播旧侧视冒充 |
| 火路打开 | 槽内粒子起燃、沿路径传播 | 后续远景与火源状态一致 |

由三维提供空间和接触底稿，漫画层负责具体原画与遮挡，程序负责时序、位置、
状态和粒子。画得好的部分沿用；只有缺少转面、受伤眉眼等可见关系时补生图。
一张生成图不能同时证明卡槽、脱槽及自由持盾三种状态。若图中烤入了盾或静态火，
先分离道具/火源并准备干净底图，再按状态合成；不能用下一张图自行“恢复”。

## 原画采用边界

- **表情线稿不做透明叠化。** 两张眉眼/嘴的结构不同，即便框外逐像素相同，
  中间权重也会出现双眼线和重嘴。`raster-face.js` 的 `expressionTransition:'cel'`
  按 `strainThreshold`（默认0.5）选单张完整表情；需要细腻过渡就补实际中间画。
  同样检查全身痛感供体，不能只修头像。低、中、高情绪值各取一帧，包含真实对白口型。

- 同一头部用嘴窗、眼窗合成表情供体。`raster-face.js` 的可选
  `expressions.strain` 保留跨口型的眉眼；情绪值只有接入对应图像才有画面意义。
- `prepare_portrait_atlas.py` 的 `halfPolygon` 同时限制半开嘴的目标区和重采样源区。
  只锁目标矩形会把矩形外的黑发/衣领压进嘴边；锁区外零差分也检测不出此错。
- [`compose_cel_regions.py`](../scripts/compose_cel_regions.py) 用指定窗锁回同尺寸
  眉眼/嘴/脸供体，保持其余像素及原透明边。它不判断表情是否符合剧情。
- [`register_cel_region.py`](../scripts/register_cel_region.py) 用已审的裁切、仿射、
  供体多边形和目标窗口合成可改变轮廓的局部原画；上身与手臂保护区保持不动。
  不适用于自动识别人体，也不允许把复杂转面无限拉伸。
- 多宫格不能按格数验收。沿近腿/远腿追踪两次经过相和接触相；彩色腿身份参考
  仅用于指导。候选若只修对一格，就只采用该格，不整套接受。转身朝向与行走
  相位分别检查，镜像参考不等于可以镜像角色的不对称装备。

## 检查层次

按**部件 × 事件 × 镜头尺度**检查，不能只设一个“战损/痛感”总开关：

| 维度 | 必须追踪的区别 | 容易漏掉的切换 |
|---|---|---|
| 装备损伤 | 盾面、持盾护臂、绑带、敌方腕扣分别记状态与可见区域 | 特写烤入裂口，但全身原画仍完整；换姿势误伤另一条手臂 |
| 物件关系 | 所有者、哪只手握、地面/槽/手臂支撑、是否释放分开 | “放下”可能仍握着压地；下一镜提起必须有离地过程 |
| 表演 | 台词意图、痛感底色、眉眼、嘴形、护伤身体姿势分别看 | 近景平静/疲倦，全身突然大幅龇牙；嘴形更换重置眉眼 |
| 身体尺度 | 头—颈—肩—胯关系与摄影放大率分别量 | 单格按全身包围盒缩放、抬脚改变裁边、插入镜头只放大人物 |
| 动作 | 起身、转向、停顿、支撑交换与根位移 | 通用匀速大步循环覆盖受伤退场，转身未完已开始平移 |
| 环境 | 火路状态、遮挡及源点随场景摄影 | 人物近景成立，回全景槽火消失或脱离槽口 |

这张矩阵需要以下可见关系才能落到画面，不能用同名字段代替：

- **拓扑与表面分开。** 裂纹、烧痕属于表面，缺口/断片改变外缘。先查未受损原图
  是否已经被错误蒙版挖掉；错误挖洞应修蒙版，真实断片才要继承到所有角度。切镜时
  同时看盾的完整剪影与裂纹分布。不同轮廓的图不能共用未经重画的裁切多边形。
- **解剖左右与画面左右分开。** 从肩→肘→腕→拇指追踪同一条手臂；“持盾臂”
  不是解剖身份，多宫格可能已经换手。左右不一致的候选逐格拒用，不因其余格漂亮
  就整套采用；也不整体镜像角色来修局部左右，从而翻转朝向和非对称装备。
- **拿起后的朝向也要继承。** 盾已离地不代表持盾姿势连续；对比盾面法向、长轴倾斜、
  手腕与肘的位置。必要时接抬起→持稳→降盾的姿势，不能在切回全景时直接换到侧垂。
- **打开要有被揭露的内部。** 门/炉膛需要内壁、门框厚度、地面延伸与前后遮挡；
  深色矩形只表明留了空位。绘画内膛配动态粒子，并在开门前、中、后看遮挡边界。
- **固定高度不证明体型固定。** 比较同朝向的头宽、肩宽、腰胯、大腿体积与肢段长度。
  先排除机位变化，再修原画比例；禁止用全身横向压窄或逐行收腰替代人体修画。
  局部换腿若破坏髋部轮廓，退回完整姿势原画；腰部零差分不是保留坏接缝的理由。

为每个受影响事件看“前因—过程—结果—下一次可见”，包括中间插入的反应镜头。
原画看不到受伤部件时写具体遮挡原因；等它重新露出后复核，不能将不可见记作
完整或已验证受伤。换姿势、换远近景、换原画来源都是检查触发点。

`checkContinuityTraces({samples,rules})` 可检查完整有序状态轨迹的单调损伤、允许
状态跳转和摄影/绘制尺度跳变。规则使用 `field/nondecreasing/transitions/maxStep`
及可选 `start/end`，字段缺失会失败。输入仍来自程序，另做关闭伤痕层的像素差分
确认它进入画面，再看实际纹理位置、大小、同一手臂与切镜继承；差分非零也不证明
画对了位置。`drawArmorDamage` 可将已审特写的同一裂损纹理投到显式表面坐标，
避免每张原画独立生成不同伤口。纹理与表面蒙版须逐姿势确认。

固定视角的人脸和硬护甲不宜用整张网格的高斯呼吸/发摆模拟生命感。出现“气浪”
先量实际网格点间距离，再查头发权重是否跨过脸和衣甲。`cel-stage.place` 的
`rigid:true` 关闭局部形变，仍保留整体位置、转角和原画替换；保留口型、意图驱动
的点头/收势，不能把全部表演冻结后宣称自然度通过。

1. 用 [`continuity-check.js`](../assets/continuity-check.js) 在切镜两侧和事件前后
   检查具体字段：卡槽时所有可见身体使用压槽姿态、未脱槽不能手持、转身结束前
   根位移为零、离场方向与朝向相容。它检查程序状态，不认证画面或自然度。
2. 查看实际输出的“前因—过程—结果—下一镜”有序帧，跟同一个盾尖、链端、
   支撑腿、眉眼和火路。特写里成立的关系必须返回全景复验。
3. 改程序后重渲整个受影响范围，并核对源文件摘要。保留原错误记录和用户发现
   来源；不把先前的后退解释改写成当时已通过转身。

粒子火不能排成等距同高的蜡烛。按槽的透视布置源点、改变高度与发射时相，并使
相邻火团适度重叠；`particle-effects-stage.js` 的 `widthScale` 可扩展炉火粒子团
横向范围，默认1保持旧效果。仍需看火槽侧壁遮挡、过曝与烟火是否盖住动作。

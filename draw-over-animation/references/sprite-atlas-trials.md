# 多宫格原画试片：密度、连续性与场景分离

适用于已有角色画风成立，想用一张多宫格补表情/动作的局部实验。用户明确要求
恢复原3D人物时，先保留该基线；新的多宫格候选独立输出，未验证前不覆盖正片。

## 格数怎样选

格数由一个动作周期的时长和所需独立姿势密度共同决定。约1秒的完整左右脚循环
可先试16格；这只是试验起点，不是“16格必然自然”的标准。接触、下沉、经过、
上升和相反脚半周期都需有序。直接重复姿势或错序画，增加格数也没有收益。

一次生成多格通常减少调用次数，但不据此承诺用量或价格更低。以实际返回尺寸
除以行列数，得到每格分辨率；例如1086×1448的4×4图只有约272×362/格，放大
并不会增加细节。需要近景时减少每张图的格数、用相邻组共享首尾锚点。
codex 通道注意：2×4 宫格+双参考图的长 prompt 任务要给足超时（borrowed_moonlight
A2：280s 超时一次，560s 通过）；宫格图的水彩墨点杂点经低 alpha 雾桥与主体连通，
普通连通域清理无效——用硬核（alpha>96）连通域筛选+膨胀回收软边。

## 从3D底稿到候选

1. 从一整段步态截取真实的完整周期。固定相机、角色尺度及根部坐标；记录脚、
   根轨迹、朝向和支撑相。参考姿势排入与目标相同的格子，不只传一个站姿。
2. 分开提供“动作参考”和“人物造型参考”，明确哪一格对应哪一姿势。整体衣甲、
   发型、武器和左右腿身份要连续。透明图检查实际alpha；预览底色不能代替检查。
3. 先按整格播放，检查相邻画和末格→首格。不要先加插帧、分腿或全身非刚性扭曲，
   以免把身份/步相问题藏在变形里。确需修型时重新限定并验收该修型范围。
4. 用同一张16格图每隔一格播放成8格对照，固定周期、裁切和尺度，才能看出增加
   中间画的影响。它不等同于与旧版8格独立素材进行前后对照。
5. 原地循环只检验姿势衔接。进入正片仍须结合根位移、地面视差、起停/转身、
   脚底接触和遮挡另验；没有这些证据时不能报告“走路已自然”。
6. **腿距变化不证明换腿。** 跟踪同一条腿的髋—膝—踝，检查两次接触相的左右
   承重交换与前后遮挡。灰色同装参考难区分时，另外导出左右腿不同颜色的ID诊断图，
   保持ID说明与造型参考分离；最终画面仍必须读出换腿。原3D参考通过不能替生成图通过。

共享模块 `assets/atlas-player.js` 提供等格整图采样与逐格曝光表。使用
`scripts/pipeline.mjs` 先prepare复制运行模块，episode保留素材、列行数、周期、
曝光与绑定数据。孤立动作试片可设置 `pilot.silent: true`；正片保留原音轨。
静帧、解码帧列和正常速度观察应分别记录。

## 先换场景，保留原人物

`assets/painted-backplate-stage.js` 将原3D人物和灯光保留，隐藏旧环境，接绘画底图
与真实阴影接收面。它仅适用于已校准的固定机位。背景绘画的地面透视、角色脚点
和尺度必须在实际画面调整；没有深度分层的柱子不能正确遮住穿行角色。

背景中的动态火焰使用共用粒子模块及前景栏杆遮挡。不能因人物恢复3D而恢复旧版
菱形/几何火舌效果。新机位、绕拍、楼梯行走及交互道具需要相应投影、深度/遮挡
或新的背景原画，不能宣称一张背景板已经提供完整3D场景自由度。

案例：同一集的程序五官和8张全身cel被用户否决后，新增16格步态及6格眨眼测试。
用户后续指出16格仍未换腿：原3D参考左右脚交换，但生成图未可靠保留腿身份与承重
交换，该候选判为失败。先前只观察腿距张开/收拢的判断不足；头发/披风/尺度也有漂移。
3D人物配绘画场景保留原来的动作，但角色的模型质感仍在。两条路线按实际试片比较，不能把
生成成功、可循环或seek通过当作美术通过。

## 双人舞蹈宫格：歌剧级 8 秒试片实录（2026-10-30 starlight_circus pilot8）

画法：关键帧宫格 → 同版式"中间画"宫格（codex："new cell N is exactly halfway in time between key N and key N+1"）
→ 第二层中间画（qa: key↔inb，qb: inb↔next key），每段动作 16–32 张画，全部同一画风/身份。实测曝光：
慢速伸手一拍四（max 6 帧），转圈与张臂一拍二。画与画之间静止，不做整体摇摆（R2 的整图摇摆被判纸片人）。

- **格子要够大**：1536x1024 的 3x2（每格 512²）放双人长裙，几乎每格裙摆被格边截成直线（最长 500px）。
  改 2x2（每格 768x512）+ prompt 明文留边（≥50px，裙摆/拖尾/举手都不得碰格边）后基本消失；残余贴边用 28px 软渐隐。
- **宫格内比例会漂**：同一张宫格下排常比上排大 8–10%，不同宫格之间人高差到 343↔469px。逐格以"几乎不动的人"
  （本例塞蕾娜，取格内右侧 42% 列的头顶→全画最低点）为尺缩放，并以她的头顶 x 做横向配准——动的人的位移就只来自画本身。
  选尺的列要避开高举的牵手（否则量到手）。
- **跨宫格配色会漂**（同一裙子 p1 锈棕、p2 偏橙红）：每张画人物像素的 Lab 均值/方差对齐到一张参考画（强度 0.85），
  交替换画不闪色。
- **转身要逐格写角度**：只写"turning"时生成的旋转不单调（背→正→背）；逐格写 0/45/90/135/180/270/330/360 度后单调。
  已生成的错序宫格可先按实际朝向重排格子再做中间画。
- **接触影逐人物**：按两人之间 alpha 覆盖最少的列分开，各自按脚底落影；踮脚/腾空者影子落在地面线、变淡变大，否则"飘"。
- **全景口型**：此景别嘴约 6px（原画）/8px（屏上），逐字口型无意义，但"换气时闭嘴"可见——按人声分轨核对每张画，
  张嘴落在换气里的画裁脸放大 4 倍做局部改闭口再锁回。codex 对个别脸部裁区会审核误拦（本例 1/4），屏上仅 3 帧的画
  直接用相邻已修中间画顶替，不跨图移植嘴。
- 执行入口：`dula-story/episodes/starlight_circus/tools/{gen_pilot8_v2,gen_pilot8_v3,render_pilot8,fix_wide_mouth}.py`
  （单集试片实现；推广到整片前应把切格/配准/配色/逐人物接触影提到本 skill 的 scripts/）。

## 转圈：逐格写角度仍会回头；镜像后半圈（星辰马戏团 R4，2026-10-30）

- 逐格写 30° 递进 + 一张宫格作下一张的连续性参考，0–180° 能单调；但**有舞伴在一侧握手时，模型画 240–330° 总把脸
  转回舞伴那侧**（R3/R4 两次同一偏差：正→右→背→右→正，用户感受为「不流畅」）。后半圈用 360−θ 的水平镜像
  （镜像件存为独立原画，其嘴型在自己的裁区另做），转完的正面画单独作收势接双人画。
- 转圈曝光按旋转角曲线反解而不是等分：θ(u)=总角·(0.6u+0.4·smoothstep(u))，起转/收尾停 4 帧、中段 2 帧，
  首尾落拍点（实测平均停 3.4 帧 vs R3 的 6 帧）。
- 转圈格按**头部竖轴**横向对齐，不按图像中心/脚底；高举的手会被量成头顶——头顶取中间 60% 列 alpha 宽 >14% 的第一行；
  全部转圈格共用一个比例（逐格按身高缩放会忽大忽小）和一个 Lab 变换（背面斗篷多，逐格匹配会闪色）。
- 曝光时刻写成 4 位小数时，帧时刻 i/30 可能略小于它而晚换一帧（计划 2 帧变 1 帧）；比较用 1e-3 容差。
- 原画上「mouth open singing」画死的嘴在跳舞段会全程张着，与歌声无关（R3 可见正脸 126/230 帧）。全景嘴型做同图
  图集局部编辑，并用 audio-perception-review 的 check_av_sync 对账实际显示的嘴。
- **托手转圈的轴心是交握的手，不是头**（R4b，用户：「旋转的时候手没有牵在一起」）：按头部竖轴对齐时举手尖在屏上
  漂 175px，从未碰到舞伴的手。按「举手尖=舞伴掌心」反解每格位置，再对头路径做 [.25,.5,.25] 平滑（各宫格举手外伸量
  不同，b≈0、a/d 60–100px，纯手锚头会横跳），手残差 ≤16px。镜像后半圈会把举手翻到背离舞伴一侧——镜像只修脸朝向，
  不修手；后半圈要重画「身体/脸朝向照镜像格、举手仍伸向舞伴」（refs: 锚 + 镜像格作姿势参考 + 前半圈宫格）。
- **宫格之间尺度不同**：同提示词同版式的四张宫格，身体像素高实测 650/605/460——比例按宫格各自归一（宫格内共用），
  色彩也按宫格各自对齐到锚；全局共用一个比例会让人物在转圈后半段缩小 30%。对照图别把每格缩放到等高再看大小。

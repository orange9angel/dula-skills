# 多宫格原画试片：密度、连续性与场景分离

适用于已有角色画风成立，想用一张多宫格补表情/动作的局部实验。用户明确要求
恢复原3D人物时，先保留该基线；新的多宫格候选独立输出，未验证前不覆盖正片。

## 格数怎样选

格数由一个动作周期的时长和所需独立姿势密度共同决定。约1秒的完整左右脚循环
可先试16格；这只是试验起点，不是“16格必然自然”的标准。接触、下沉、经过、
上升和相反脚半周期都需有序。直接重复姿势或错序画，增加格数也没有收益。

一次生成多格通常减少调用次数，但不据此承诺用量或价格更低。以实际返回尺寸
除以行列数，得到每格分辨率；例如1086×1448的4×4图只有约272×362/格，放大
并不会增加细节。需要近景时减少每张图的格数、用相邻组共享首尾锚点。
codex 通道注意：2×4 宫格+双参考图的长 prompt 任务要给足超时（borrowed_moonlight
A2：280s 超时一次，560s 通过）；宫格图的水彩墨点杂点经低 alpha 雾桥与主体连通，
普通连通域清理无效——用硬核（alpha>96）连通域筛选+膨胀回收软边。

## 从3D底稿到候选

1. 从一整段步态截取真实的完整周期。固定相机、角色尺度及根部坐标；记录脚、
   根轨迹、朝向和支撑相。参考姿势排入与目标相同的格子，不只传一个站姿。
2. 分开提供“动作参考”和“人物造型参考”，明确哪一格对应哪一姿势。整体衣甲、
   发型、武器和左右腿身份要连续。透明图检查实际alpha；预览底色不能代替检查。
3. 先按整格播放，检查相邻画和末格→首格。不要先加插帧、分腿或全身非刚性扭曲，
   以免把身份/步相问题藏在变形里。确需修型时重新限定并验收该修型范围。
4. 用同一张16格图每隔一格播放成8格对照，固定周期、裁切和尺度，才能看出增加
   中间画的影响。它不等同于与旧版8格独立素材进行前后对照。
5. 原地循环只检验姿势衔接。进入正片仍须结合根位移、地面视差、起停/转身、
   脚底接触和遮挡另验；没有这些证据时不能报告“走路已自然”。
6. **腿距变化不证明换腿。** 跟踪同一条腿的髋—膝—踝，检查两次接触相的左右
   承重交换与前后遮挡。灰色同装参考难区分时，另外导出左右腿不同颜色的ID诊断图，
   保持ID说明与造型参考分离；最终画面仍必须读出换腿。原3D参考通过不能替生成图通过。

共享模块 `assets/atlas-player.js` 提供等格整图采样与逐格曝光表。使用
`scripts/pipeline.mjs` 先prepare复制运行模块，episode保留素材、列行数、周期、
曝光与绑定数据。孤立动作试片可设置 `pilot.silent: true`；正片保留原音轨。
静帧、解码帧列和正常速度观察应分别记录。

## 先换场景，保留原人物

`assets/painted-backplate-stage.js` 将原3D人物和灯光保留，隐藏旧环境，接绘画底图
与真实阴影接收面。它仅适用于已校准的固定机位。背景绘画的地面透视、角色脚点
和尺度必须在实际画面调整；没有深度分层的柱子不能正确遮住穿行角色。

背景中的动态火焰使用共用粒子模块及前景栏杆遮挡。不能因人物恢复3D而恢复旧版
菱形/几何火舌效果。新机位、绕拍、楼梯行走及交互道具需要相应投影、深度/遮挡
或新的背景原画，不能宣称一张背景板已经提供完整3D场景自由度。

案例：同一集的程序五官和8张全身cel被用户否决后，新增16格步态及6格眨眼测试。
用户后续指出16格仍未换腿：原3D参考左右脚交换，但生成图未可靠保留腿身份与承重
交换，该候选判为失败。先前只观察腿距张开/收拢的判断不足；头发/披风/尺度也有漂移。
3D人物配绘画场景保留原来的动作，但角色的模型质感仍在。两条路线按实际试片比较，不能把
生成成功、可循环或seek通过当作美术通过。

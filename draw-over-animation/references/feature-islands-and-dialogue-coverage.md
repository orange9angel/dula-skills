# 同图五官遮罩与对白覆盖

borrowed_moonlight R3 曾通过口型源摘要和静帧检查，用户仍指出中景嘴眼静止、
说话与眨眼有矩形边、老人穿桌。原通过记录保留；这些问题是用户反馈触发的返修。

## 先核对真正进入画面的执行层

近景肖像有 `face.paint()`，不代表中景/全身 cel 同样消费了口型。按最终对白的
时间窗逐一查实际选中的 cel：可见正脸需要动态五官；背面、道具插入与画外音分别
登记。至少验证每段可见对白出现两种实际嘴形，并看连续原生裁区。不能只检查
voice_envs 文件存在或源哈希一致。轻声长句需要按该句有声能量校准阈值；保留零能量
闭口，不用持续张嘴或与声音无关的正弦振动伪装说话。嘴形曝光也要固定到输出帧。

## 源图本身也可能有两套眼睛

R3 的女孩 blink 源图保留了睁眼的上缘，下面又画了闭眼线。局部锁回和框外零差分
无法发现该原画错误。先看原始供体与本底的原生眼区，必要时重新编辑；羽化不能
修复重复眼线。之后还要看「表情 + 开口 + 眨眼」叠加，不只验收三个独立极值。

`assets/feathered-variant-face.js` 是同图局部变体合成器：

- `variants[key]` 包含 `src`、目标 `rect: [x,y,w,h]`，可选
  `islands: [[cx,cy,rx,ry], ...]` 和 `feather`。
- 双眼各有一个完整遮罩，遮罩内核必须覆盖全部旧眼形。横跨双眼的单椭圆会削掉
  外侧/上方，留下旧睫毛；不能为消除矩形而把需要替换的像素也淡掉。
- 表情只绘制声明的局部区域，不整幅替换肖像背景。五官遮罩外和矩形边保持零覆盖。
- `sourceRect`、`sourceSize` 支持来自原图自身裁区的编辑图集，明确返回尺寸与源图
  坐标映射。它不是跨图移植许可；不同人物、朝向、生成底图之间不移植五官。
- 全身动态纹理必须使用同一原图的 alpha bbox，不可按每个变体分别 trim 后改变
  原点。画面仍是有限口型原画，不宣称逐音素精确或任意角度表演。

`image-lipsync/scripts/pack_edit_targets.py` 按 JSON 把不同目标图的原生裁区打包，
保留每格来源与坐标。只做无损排版，实际嘴眼变化仍由允许的图像编辑通道生成。
返回图不得整格覆盖人物；校正尺寸后，仅采样各自对应的五官区域。

```json
{"cell":[400,400],"columns":4,"targets":[
  {"id":"hero_hold","source":"../cels/hero_hold.png","crop":[300,0,400,400]}
]}
```

## 房间里的人需要共同空间与交流方向

脚底落在桌后地面、再盖桌前沿，仍可能留下腰身像嵌进桌面的画面。以实际桌面高度、
身体体积与工作动作重新排站位；有空间时可站桌侧，保留完整鞋底和桌侧净空。
为双方准备向内的斜侧原画，保持反打方向、同一场景坐标与实际光源。中景要能读到
谁问谁、谁在听；头像轮番正对观众不能代替交流。角色与桌面阴影颜色一致也不能
替代正确比例、遮挡与手部动作。

只露半个人的反打镜头不能把「裁掉的较低鞋底」当作脚悬空；接触检查只对实际完整
入镜的支撑区作结论，明确记录出画，不能把所有失败都以遮挡豁免。

## 特效讲述变化

`assets/story-particles.js` 提供确定性出生、寿命与轨迹的柔边粒子。单集绑定真实
瓶心、灯芯、泪滴和接收目标，安排起因、传播、抵达、余韵。不要把所有持物统一
挂到 `body.y - height * 常数`；不同原画中的手与道具位置不同。
扩散粒子不要持续盖住眼睛和嘴。云层条带需要四边渐隐，检查移动到画幅中央时
是否露出整条矩形边；只在天空静帧看过一处不够。

这组工具解决限定视角的组合与覆盖问题，不自动保证自然表演或审美通过。最终
必须从编码后片段复看嘴眼、双人构图、接触和关键特效，并记录抽帧与实时观看区别。

## 首次显示动态纹理的捕获稳定性

R4 分幕导出时，200/276/374秒首次出现相关绘画层，顺序与跳转PNG校验有极少量
1 LSB像素差异（200秒复现为28像素、最大通道差1）。不得把失败直接改为通过或
降低整个剧集的容差。先确认同一时刻重复绘制会稳定，`pipeline.mjs` 的
`pilot.settleBeforeCapture: true` 会在正式 `renderAt(t)` 前再执行一次 `stepAt(t)`；
时间不前进，输出仍用严格PNG摘要比较。只为受影响片段启用并重新导出/回测。
这要求运行层按绝对时钟求值，不能用于掩盖累积动画或随机数状态错误。

# Dula接入与能力清点

用于真正接入逐镜作画层。以下是接口需求和实施顺序，不是现成API；生产前读取
当前viewer/渲染器/素材链，明确“已存在、可复用但需适配、待实现”三种状态。

## 最小镜头资料

在episode内保存一份修型记录，格式可沿用已有工具。至少包含：

| 项目 | 内容 |
|---|---|
| 来源 | 视频、剧本、相机/角色代码和关键素材的版本或摘要；输出尺寸与fps |
| 时序 | 现有条目/镜头/cue引用、相对偏移、派生输出帧区间；发生剪辑时保留源/成片映射 |
| 意图与范围 | 哪个角色、什么变化、局部/肢体/整人物替换、允许改动和保留项 |
| 原画 | 文件、动作阶段、身份参考、候选状态、适用转面范围和入口/出口 |
| 合成 | 移除区域、alpha、干净底图、跟踪空间、遮挡层、阴影/反射处理 |
| 调度 | 曝光、过渡方式、口型通道、切镜重置、画面修型与接触锚点关系 |
| 证据 | A/B输出、实际查看方式、结果、未验证范围和制作耗时 |

剧情和总时序继续由`script.story`派生。新镜头或命中点必须先改正本；只调整同一
窗口内的眉眼过渡可记录相对帧偏移。新增JSON只有在真实读取器接入后才是执行配置。
对缺失cel、无效时窗和过期来源报错；诊断回退到原画面时也要显式报告，不能静默
跳过作画层却生成“通过”的成片。

## 从底稿到分层合成

1. 更新姿势、道具和最终相机，刷新世界矩阵，再取得屏幕投影。若有相机抖动，
   底稿与补丁共用同一抖动结果，不在补丁里再加一次。
2. 导出原画参考。局部替换需要对应区域的无旧五官/旧线条底图；改轮廓或整人物
   替换需要不含被替换人物的clean plate。渲染同一相机、同一时刻、同一场景状态。
3. 为原人物移除区、身体/装备和遮挡物生成所需蒙版。新轮廓缩小时要清掉旧边缘，
   扩大时也要补出正确前后关系。只在beauty图上叠alpha无法擦除原人物。
4. 合成按实际前后关系组织：背景与后景效果→人物/局部cel→前景物体与前景效果
   →字幕/字卡。盾挡住脸、手绕到武器后面时应拆层或提供局部深度关系，单个
   平面的固定深度不足以处理所有遮挡。深度不可用时用逐镜绘制/烘焙蒙版。
5. 核对地面接触影、投影和反射。改变轮廓后旧三维阴影可能露出另一套姿势；按
   镜头保留可用的阴影代理、重画阴影或重新导出，不能无条件声称原阴影仍正确。
6. 统一alpha约定、色彩空间和输出尺寸，使用无损中间素材避免边缘反复压缩。
   透明边出现黑/白圈时先查预乘alpha和底色污染，不用大羽化掩盖。

三维深度、ID蒙版、clean plate和运动向量不是现有beauty视频天然携带的信息。
最小试片仅实现它真正需要的通道；不要为一个眉眼实验先建设整套通用渲染器。

## 跟踪与曝光的实际关系

头部小角度可使用表面/头部局部坐标或已标定的面部控制点；超出原画可用角度切换
新原画。不能让远侧眼穿过鼻梁，也不能用全屏billboard保持所有五官正对观众。
屏幕空间整人物替换优先锁定当前镜头；若相机继续运动，使用对应投影的关键画与
过渡，或验证有效的2.5D分层。单个2D仿射变换不保证大范围透视成立。

姿势保持期间，相机更新、人物根位移和支撑脚需要共同设计；把脸固定在旧屏幕坐标
会漂，把整个人物只平移会滑脚。持盾/持械时人物手、道具与接触效果使用一致采样。
所有取帧由绝对时间/帧号决定，避免调用次数推进的状态。缓存键包含镜头、角色、
原画、曝光、口型与有效视角；切镜清理失效状态，同一帧重取不累积半透明颜料。

## 已有自包含viewer的接入示例

2026-10-24核查的`stardust_clad_s1e2/viewer_palace.js`为：

```text
poseAt / scene.update
→ 最终相机
→ setEmotion / face.setActing / lookAtWorld / mouth.apply / softPortrait.update
→ 链与战斗效果更新
→ renderer.render → ctx.drawImage → overlay → JPEG取帧
```

当前`overlay`混合了字幕、招式文字、命中光与淡出。不能把人物cel随便追加在
整个overlay之后，否则会盖住文字与效果；实际接入需拆分合成职责。

| 能力 | 此次源码所见 | 制作时的接法 |
|---|---|---|
| 绝对时间取帧 | `window.renderAt(t)`、`stepAt(t)`已存在 | 沿用并验证新增层的顺序/seek一致性 |
| 表情、视线与音频口型 | 通道已存在，基础表情与softPortrait有执行顺序 | 明确每项的写入者；新表情不能被旧眨眼/贴图绘制覆盖 |
| 最终相机与接触点 | 相机、contacts与运行态可读取 | 同一时刻投影，检查补丁后的可见接触 |
| 二维绘制入口 | 最终Canvas已存在 | 可作为合成入口，但当前不含通用人物cel调度 |
| 干净底图、遮挡和旧轮廓清除 | 此入口未暴露通用导出通道 | 在试片适配中实现并验证，不假设现有trace已经包含 |
| 无损中间帧 | 当前返回JPEG | 新试片导出PNG或像素缓冲；不能只改扩展名 |

本表是一个已查看版本的接入例子，不代表其他episode具备同样接口。合成组件成熟
后放`dula-engine`，表情/姿势绘画资产放`dula-assets`；episode保存镜头映射和试片。

## 验证范围与停止条件

- 确定性：按顺序渲染，与直接seek、反向seek和重复同帧比较。用最终无损输出
  检查状态残留；编码后另看边缘和闪烁，不放宽阈值掩盖实际几何变化。
- 覆盖：曝光表无意外空洞/重叠，原画可用角度覆盖当前转面，切镜没有上镜残留。
- 合成：检查新旧轮廓的并集区域、遮挡交接、露出的背景和投影；移除区域之外
  只对声明不变的图层做diff，动态火焰/相机导致的变化不自动判为修型泄漏。
- 接触：原三维数值报告继续证明原底稿；二维替换另检手—物、脚—地与命中点。
  偏差阈值按最终画幅和动作选择，不能拿三维毫米值冒充二维可见接触证明。
- 声画：保留最终对白/音乐源与发声窗口；替换嘴型接入真实口型事件。只做画面时
  检查音轨保留，重封装后的PCM/时偏按实际路径验证，不只比AAC文件哈希。
- 审美：比较意图、动作线、受力和人物身份；跟踪误差为零不代表有表演。

先交付一个可读且稳定的短镜头。若局部变形在转面处反复失败，改用更多角度原画
或扩大替换范围；若仍无收益，报告已尝试路径与证据，不扩渲整集或改用未授权的
生成视频服务。工艺文档、静帧和动态成片分别标注完成程度。

# 固定视角原画的有限关节运动

用于已认可同框原画中的放麦、木偶小幅敲胸、伸手等有限动作。路线为驱动层：
手、手指和道具使用同源像素刚性运动，前臂/上臂可按空间两骨投影缩短。它不生成
转面、新露出的手背或衣物内侧，不能代替大幅姿势变化所需的新原画。

共享实现：`assets/painted-part-rig.js` 提供部件、清理底图和空间两骨求解；
`scripts/build_part_masks.py` 从单集 `source/parts/maskSeeds/maskDirectory` 制作 alpha。
`eraseParts` 与 `clearPolygons` 单独定义旧轮廓清理；`occluder` 保留前景遮挡。
依赖 Pillow、NumPy、opencv-python-headless。调用：

```powershell
python <skill>/scripts/build_part_masks.py EP --config config/part_rig.json
```

先有完整部件、干净底图和遮挡层，再移动；原画背景不能跟着手一起旋转。
骨轴投影只用于肢段，手和道具不一起缩放。遮挡揭露新表面时应补画，不能无限拉长。

## R2 换画变形与 R3 内部失败

星辰马戏团 R2 中，用户指出眨眼、敲胸变形，其他动作不流畅。原因并非导出帧率：
木偶三张动作画连纽扣与红外套一起变，放麦只有三次大姿势替换，眼区替换连眼窝皮肤
一起变。配准、PNG 确定性和声音通过都没有排除这些缺陷。

R3 内部试验又出现三个必须拒收的结果：

- 使用分割后的部件 alpha 同时清理原位置，漏掉旧手边缘和暗线，留下双手/残臂。
  旧轮廓清理蒙版须覆盖完整旧形，独立于前景分割；只在清理区采样干净底图。
- 把卷袖和前臂一起绕手肘转，袖口脱离上臂。先在原生刻度图读实际关节和袖口开口，
  保持袖口不动，转动开口里的裸前臂；生成的“移除袖口底图”因此未用于最终版本。
- 手工 polygon 与前景 seeds 放错，蒙版把前臂切成细丝。必须沿上臂—肘—腕—手逐段
  看 RGB+alpha。可为已知内部点配置 `maskProbes: {part:[{point:[x,y],minRadius:5}]}`；
  工具用距离变换拒收过窄的必要内截面。该数值不评判外轮廓或解剖。

平面两骨求解曾令肘部异常外翻，使用有深度 pole 的空间求解改善了过渡。直接程序填色
的裸臂与原画笔触不合，未采用；最终仍用原画肢段纹理。空间投影也会改变可见宽长关系，
要看极值和中间画，不能用骨长恒定宣布造型正确。

## 固定眼窝的眼睑

`assets/fixed-eye-rig.js` 在原眼位置收合上下眼睑，虹膜保留原像素，通过眼裂裁切显示；
不缩放虹膜，不替换鼻子、眉毛和整脸。完全睁眼时直接保留原画。
两眼分别量六点贝塞尔边界、皮肤采样点和眼线色。

只让上眼皮往下盖，曾留下底部眼白；远侧眼坐标又曾量到头发，导致一眼闭合、另一眼
仍亮。必须检查两眼的完整闭合和恢复；贝塞尔控制点不是曲线极值，不能把控制点落在
眼白下方当成已覆盖。皮肤填充与上下眼裂须在闭合时汇到同一曲线。

## 光影与验收范围

移动部件不能在新位置直接采样静态背景受光图，否则原来脸旁的手移到裙前会变成异色块。
`assets/painted-lit-overlay.js` 让独立部件随同一照明强度变色；当前是有限二维材质近似，
不提供新的物理投影和移动阴影。具体增益由本次画作试样确定，不当作通用真实受光模型。

先看最终编码的原生连续裁区：一次完整眨眼、敲击的预备—接触—恢复、整个放麦及伸手，
再回到整个人物和画幅。顺序/seek 摘要、轨迹步长、骨长和音频时间只作各自技术证据。
R3 完成 22 秒有限动画修订与连续帧复看；正常速度观感、身体协同与精细表演仍不能由
这些记录自动批准。保留 R2 与内部失败片，避免把返修后事实倒写为上轮已发现。

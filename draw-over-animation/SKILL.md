# 二维作画与表演修正层

让三维提供空间、构图、运动参考和接触锚点，让最终人物画面由逐镜作画决定。
可以改变眉眼、颧颊、下颌、手型、肢体投影与整个人物轮廓，不必把每张画反向塞回
一套通用模型。三维本身也能做细腻表演；本工艺增加的是按镜头自由画形和安排曝光
的能力。它需要原画与过渡画，不能仅靠风格滤镜、描边或减少帧数完成。

## 任务边界和既有能力

- 设计/建立skill时：读实际片段与执行链，交付工艺、接入位置和试片方案。
  不默认为重制全片，也不将规范文件说成已经可运行的合成器。
- 已授权制作时：完成代表镜头的原画、合成、实际导出和复看，再按结果扩展。
  沿用用户已授权的普通迭代；不新增逐张批准流程。
- 本 skill 已有参数化的动作烘焙、试片渲染、对照打包、检查执行器，以及二维关节修正
  与固定点运行模块。新集直接使用这些共享代码；角色绑定、原画落点和镜头仍需适配。
  clean plate、遮挡蒙版及多角度原画是否齐备须按项目核实，不能把有配置当作已接入。

先读当前episode的NOTES、实际交付视频、相关审查记录和`script.story`。
使用[角色注意力巡检](../character-attention-review/SKILL.md)定位需要改变的画面关系；
沿用[质量与效率标准](../direct-animation-craft/references/production-efficiency.md)。
只加载当前模式需要的下列参考：

- 设计表情、姿势、关键画和过渡：读[作画与表演](references/acting-and-cels.md)。
- 实现跟踪、遮挡、曝光、导出或检查能力缺口：读[Dula接入](references/dula-integration.md)。
- 烘焙动作、导出试片、跨集复用控制器：读[共享执行工具](references/executable-pipeline.md)。
  通用代码在本 skill 的 `scripts/` 和 `assets/`；不从另一集复制整套 tools。
- 将已认可方案覆盖整片，或同时补全身表情、发梢和支撑关系：读
  [整集作画与局部控制](references/full-episode-direction.md)。用户明确要求整片时，
  用完整时轴验收覆盖；把一个新窗口接回旧片不等于完成整片改造。
- 用多宫格补表情/走路，或恢复3D人物、只替换场景时，读
  [多宫格原画试片](references/sprite-atlas-trials.md)：固定动作周期比较格数，检查实际
  单格尺寸与身份漂移，使用共享整格播放器；场景底图的摄影限制另行验证。
- 只让生成原画处理脸、发、衣褶等难画区域时，读
  [按区域与关键时刻修画](references/region-guided-redraw.md)：保留3D动作和接触，区分
  表面细节与轮廓替换；有限视角可用曲面投影模块和同机位区域差分检查，明确部件
  蒙版、上下文、复用范围和待实现能力。
- 局部贴画仍受坏形体限制，或需要比较动作参考、整人物原画和时序生成时，读
  [角色混合路线实验](references/hybrid-character-routes.md)。区分已见静帧收益与
  动态失败，不能把精确3D对应图当成能理解新画形的自动中间画。
- 用户要求兼顾效果与成本、由agent决定混合路线时，读
  [按动作资产控制生成成本](references/hybrid-character-production.md)。按动作周期复用，
  只补明确缺口，记录候选的实际采用收益；不把多宫格数量当作自然度。

## 在现有流程中的位置

```text
剧本意图、对白与动作锚点
  → 3D空间/接触/动作底稿 + 基础cel-look
  → 逐镜表演设计 → 原画/过渡画 → 二维替换与合成
  → 线色统一、最终特效与字幕 → 连续片段验收
```

二维作画可以要求回修底稿的姿势与摄影；它是有反馈的制作阶段。新的动作因果或
镜头时序回到剧本正本，单镜的画形与曝光留在引用该正本的修型记录。

| 本镜头缺口 | 选择 | 保留的约束 |
|---|---|---|
| 眼神、嘴角、脸颊或颈部不表达意图 | 局部替换，必要时包含整头和颈肩 | 身份、头部空间朝向、口型时点、头发与脸的遮挡 |
| 拳、手腕、肩腰或受压轮廓被模型限制 | 肢体/躯干原画与过渡画 | 支撑和持物锚点、动作方向、前后遮挡、装备语义 |
| 高张力透视、转面或极值姿势无法由局部补丁成立 | 整人物cel替换，3D只留空间与接触参考 | 相邻画的身份与因果、场景尺度、关键接触和进出镜 |
| 原位姿已经成立，只是线条/高光不合画风 | [cel-look](../cel-look/SKILL.md) | 不凭空增加绘画工作 |
| 走路路线、重心或命中时点错误 | [direct-animation-craft](../direct-animation-craft/SKILL.md)、[walk-director](../walk-director/SKILL.md)先修 | 不用贴片掩盖未完成的动作 |

不要求每镜走最高成本路线。按本镜头所需表现决定替换范围；大幅改变身体轮廓时，
只覆盖眼嘴通常不足以统一整个人物。不要让“沿用骨架”变成不能重画姿势的限制。

## 执行闭环

1. **锁定基线。** 记录视频摘要、输出帧率/画幅、镜头范围和保留项。实际解码确认
   要看的脸、手或身体可见；剧情cue不等于该时刻一定有对应特写。
2. **写一句表演目标。** 例如“先压住痛，再看清对手，决定继续守住”，并指出
   画面中应发生的变化。不能只列`angry=0.8`或“更有动画感”。
3. **画关键关系。** 为起势、转折/极值、恢复做可比较的画；同时确定必要的过渡画、
   支撑点、视线对象和遮挡。原画先在最终画幅里看，脸好看而身体失去重量不能通过。
4. **实现最小连续片段。** 选择跟随形变、替换cel或整人物作画。关键时点用已审
   原画钉住；快速转面、露出原来被挡住的区域、拓扑变化处补新画，不无限拉伸贴片。
5. **合成并继承声音。** 用明确的移除区域、干净底图和遮挡层替换旧轮廓；对齐
   原对白与接触事件。用`cel-look`统一新增画的线色与光向，不自动重做配乐。
6. **比较实际输出。** 同机位A/B、极值与过渡画、正常速度片段；补查切镜边界、
   转面、遮挡、重复取帧及seek。只看过帧列就如实写帧列，不能代称正常速度观看。

先做能覆盖风险的短样片，例如一个表情镜头和一次完整格挡。初轮只改变作画/
表演；确需改摄影则另存版本，避免把拉近镜头的收益误记成绘画收益。代表镜头
通过后，才把已验证内容提取为可复用的表情原画、手型、姿势模板与合成组件。

## 连续性与生成纪律

- 生成图片用于原画候选。需要时联用[连续分镜图](../build-continuous-story-images/SKILL.md)
  的身份参考、相邻关键画及候选验收；实际调用遵循当前可用图像工具及对应skill。
  每帧独立重绘不作为默认连续动画方案，插帧也不能修正错误身份或动作路径。
- 位图局部编辑可复用[image-lipsync](../image-lipsync/SKILL.md)的锁区工具；它证明
  的是单张底图的局部一致性，不提供三维跟踪、遮挡或长对白自然演绎保证。
- 移动镜头的补丁跟随头部/表面坐标，不能将固定屏幕矩形当通用绑定；保持姿势时，
  摄影机仍可推进，但脚、手及其接触物须使用兼容的采样策略。
- 本路线不要求I2V。其他skill的历史视频生成方案不能自动替换本任务的逐镜作画。
  按当前用户的生成预算和后端选择执行；无预算时仍可手工/程序绘制关键画，但不得
  把缺少转面和身体动作的静态立绘缩放当作等价交付。
- 动态特效必须使用粒子，包含招式、锁链附焰、命中以及场景火把、炉火、烟和余烬。
  执行[粒子特效规则](../direct-animation-craft/references/particle-effects.md)，禁止菱形/
  星形闪光、几何火舌、光环及折线光束替代；人物二维化不要求粒子一起漫画平涂。
  纸片感先区分身体自身缺少转面/体积变化，还是与场景接合不足。前者回查肩胯、
  肢体遮挡与连续画形；后者检查接触影、环境光色与前后遮挡。限定范围的轻融合
  可复用 [共享工具中的粒子与场景接合](references/executable-pipeline.md)，保留已认可原画。

## 交付和判定

交付本镜头的表演说明、原画/过渡画、曝光与合成记录、A/B片段、复看结论。制作
资料放episode；通用作画资产进`dula-assets`，通用渲染/合成执行进`dula-engine`。
本skill保存方法、有效教训和共享制作工具，不另建完整渲染框架。剧集专用造型与镜头
留在内容仓；相同的导出、验证和动作控制逻辑不要按集复制。

通过的证据应回答：观众能否读到新的意图与受力？角色是否仍是同一个人？变化
能否连续成立？手脚与武器是否仍接触正确？旧线条、脸漂、胶片式抖动是否已排除？
技术检查与视觉结论分别写。单张美图、参数增加、配置验证通过均不等于动态达标。

连续两轮同一修法没有可见收益时，复盘替换范围和原因：局部补丁受限就试整头/
整人物原画，连续性失控就缩小到可验证的镜头并补过渡；保留失败证据，不反复增加
滤镜或降低表演目标。最终状态明确区分“工艺已定义”“静帧试样”“动态试片通过”
和“已接入成片”。
